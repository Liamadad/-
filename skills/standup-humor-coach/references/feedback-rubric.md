# 点评量规：怎么评，用户才会进步

这份文件管两件事：怎么给用户的尝试打分；怎么说，他才会真的变好笑，还愿意接着练。

文中示例只用来理解点评方法；点评时用用户自己的句子，不要原样复用。

## 1. 什么时候读这份文件

- 用户交来自己写的东西要你评：每日一练的答案、聊天复盘里他自己写的新回复、段子工坊里他先给的笑点、陪练复盘时他的句子。
- 用户带回真实反应（群里的回复、截图、聚会上讲完的情况），要你解读、记进步。
- 给你自己的示范打分、筛选，用 `references/ai-humor-engine.md`。两份是同一套八个维度，这份只管怎么评用户、怎么跟用户说。

## 2. 八个维度速查

每项 0–2 分，满分 16。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 意外 | 听到一半就猜到结尾 | 有点意外 | 结尾完全没想到 |
| 秒懂 | 要解释，或要想三秒以上 | 想一下能懂 | 一听就懂，回头看很合理 |
| 共鸣 | 听众没经历过，没感觉 | 部分人有感 | "对对对，就是这样" |
| 具体 | 全是泛称 | 有一个具体细节 | 细节能拍照，而且来自真实情境 |
| 态度 | 纯描述 | 有情绪，但立场不清楚 | 立场鲜明，说出了没人说的真话 |
| 简洁与笑点位置 | 冗长，笑点埋在中间 | 稍长，或笑点后面有尾巴 | 没有废字，笑点词在最后 |
| 新鲜 | 库存梗、模板、烂梗 | 题材常见，角度新 | 题材和角度都新 |
| 场合与靶子 | 打弱者或对方痛处，或不合场合 | 有点风险 | 打自己或往上打，适合这个场合和关系 |

**一票否决**：秒懂或场合与靶子任何一项 0 分，总分再高也是 😐。
- 秒懂 0 分：先补背景或搭桥，别的都先不谈。
- 场合与靶子 0 分：先说"这条先别发"，一句话说清谁会受伤；观点可以留着，换个靶子重写。模型当裁判时会给带刻板印象的笑话打高分，所以这一维要比你的直觉更严。

**换算成笑声计**

| 总分 | 笑声计 | 意味着什么 |
|---|---|---|
| 0–8，或被否决 | 😐 还不是笑话 | 还不能用。指出最弱的一维，从那里重写 |
| 9–11 | 😊 会心一笑 | 有笑点了。实时接话，发出去不亏，接住就算赢；要当段子讲，还差一步，说清差在哪 |
| 12–14 | 😄 能笑出声 | 可以发、可以讲了，去真实场合测 |
| 15–16 | 🤣 爆笑 | 很少见。给之前先怀疑自己打高了 |

**分数只给你自己看。** 打分是为了排序、找出最弱的一维。用户看到的只有笑声计和最弱的那一维，用大白话说（"最弱的是笑点位置：笑点后面还拖着半句"），不要说"13/16""8/10"。模型挑"最好笑"的选项，和真人的选择只比随机略好，还偏爱给高分；报个数字，会让你的猜测看起来像测量结果。所以笑声计也要说成猜测："我猜 😊 会心一笑"。emoji 后面总带上文字。笑声计不用 🙂：它在微信里常被读成阴阳怪气。

拿不准时，做四个快测：念出来，哪里卡、哪里拖（简洁）；这条会不会被人截图转发到别的群（🤣 的门槛）；朋友能不能在饭桌上复述它（结构清不清楚）；被调侃的人就在群里，他会笑还是退群（靶子）。

## 3. 点评三步

先在心里把八个维度过一遍，找出最弱的一维。然后只说三件事。

**① 一个具体的亮点。** 点名到那个词或那个细节，说它好在哪：具体、意外，还是态度准。这一步既是鼓励，也告诉他哪里要留着。实在找不到亮点，就夸他做对的那个动作，同样要具体，比如"你注意到了她一句话里说了三遍 literally，这就是可以玩的点"。

**② 最大的一个问题，只说一个。** 按这个顺序挑：
1. 有否决项（秒懂、场合与靶子），先说它。
2. 前提不成立（没有态度、没有共鸣），说前提。前提不成立，改措辞没用。
3. 上面都没问题，挑"改了这一处，笑声计能跳一档"的那个。

说清为什么，最好说听众在那一刻脑子里发生了什么："对方看到'哈哈哈'，就不用笑了，你已经替他笑完了。"

**③ 在他的句子上改。** 最小改动：保留他的想法、他的词、他的口气，能只动结尾就只动结尾。改完要像他会发的消息，不像段子手，更不像 AI。之后可以再给一个不同方向的版本，换一招，标上招式名。示范最多两个，示范里不解释为什么好笑。

收尾两句：
- **笑声计**：给他的原版打一档，附上最弱的一维。改后的版本只说"我猜能到 😄 能笑出声"，让他拿去测。
- **轮到你**：给一道同一招的新题，或者让他照这个思路再写一版。他自己写，才学得会。

整段点评不超过手机一屏。另外四条：
- 一次交来好几条（比如连珠炮）：每条只给笑声计，挑最有潜力的一条走完三步。
- 他的句子已经到 😄：直说"这条可以发了"，别为了凑满三步硬挑毛病；可以送一个追加笑点（tag）当加分项。
- 评一整段故事：三步照用，但只挑一拍改。先确认前提能用一句话说出来（"这件事好笑在哪"），再找最可能冷场的那一拍，不整段重写。
- 练习时，可以先问他"你猜这条能到哪一档"，再给你的。他猜得越来越准，说明编辑的眼光在长。

### 完整示例：家族群

题目（每日一练，练"认同并放大" Agree and Amplify）：你妈在家族群里说："听说美国最近很乱，你晚上不要出门。"

用户写的：

```
放心吧妈，我晚上从来不出门，我连白天都不怎么出门哈哈哈，我就是个死宅。
```

点评：

- **亮点**："连白天都不怎么出门"——顺着你妈的话又往上加了一层，这正是"认同并放大"要的那一步。方向对了。
- **最该改的一处**：笑点后面还拖着半句。"我就是个死宅"是在给笑点下结论，等于自己解释了一遍；"哈哈哈"是替你妈把笑笑完了。别贴标签，给一个证据，放在最后。
- **在你的句子上改**（只动结尾）：
  ```
  放心吧妈，我晚上从来不出门。
  上次出门，还是去拿你寄的快递。
  ```
- **换个方向**（文体错位 Register Clash：用新闻腔汇报自己有多宅）：
  ```
  收到。本人已连续 9 天未离开宿舍，安全形势总体稳定。
  ```
- **笑声计**：原版 😊 会心一笑，最弱的一维是笑点位置。改后我猜能到 😄 能笑出声，发出去，把你妈的回复带回来。
- **轮到你**：同一招，接你妈的下一句："你爸说你视频里看着瘦了。"

### 三个短例

**约会：只有抱怨，没有角度。** 对方问："来美国以后最不习惯什么？"

```
用户：最不习惯的是吃的吧，美国的东西又贵又难吃，我天天想吃火锅。
```

- 亮点："天天想吃火锅"是真情绪，火锅是这句话里最好的素材。
- 最该改的一处："又贵又难吃"谁都会说，只有不爽，没说具体哪里不对劲，初次约会听着还像在倒苦水。收窄到火锅一件事，给一个数字，再给一个你为它干的离谱事。
- 改：
  ```
  最不习惯的是，火锅要 40 刀一位。
  我现在一个月只吃一次，前一天开始禁食。
  ```
- 笑声计：原版 😐 还不是笑话，最弱的一维是态度。改完的结尾还留了个口子，对方很可能接一句"哪家这么贵？"。约会里，能被接住的玩笑比一句封顶的妙语值钱。

**聚会讲故事：转述，而不是演。**

```
用户：我有一次用了室友的洗洁精，她第二天就在冰箱上贴了张纸条，说希望我们能沟通一下共享物品的问题，最后还画了个笑脸。我当时真的特别无语。
```

- 亮点："最后还画了个笑脸"——整件事最好笑的就是这个笑脸。
- 最该改的一处：你在转述，还替听众下了结论（"特别无语"）。听众没看到那张纸条，就没法跟你一起无语。把纸条念出来；结尾不说感受，说你对那个笑脸的判断。
- 改：
  ```
  我用了一次室友的洗洁精。
  第二天，冰箱上多了一张便利贴：
  ［用最温柔的语气念］"Hi～关于共享物品，我们可以找时间聊聊吗？"
  下面画了个笑脸。
  ［停一拍］
  那是我来美国以后，见过最吓人的笑脸。
  ```
- 笑声计：原版 😊 会心一笑，最弱的一维是具体：纸条原话没出现。下一轮可以练追加笑点（tag），比如："第三天我买了两瓶新的放回去，也画了个笑脸。我们到现在都没聊。"

**群聊：靶子不对（一票否决）。** 群里在吐槽这学期的统计课。

```
用户：那个 TA 的口音我是真的服，讲了半小时，我以为他在念咒。
```

- 亮点："讲了半小时"——真正的痛点你抓到了：听了半小时，什么都没学到。这个观点留着。
- 最该改的一处：靶子不对。口音是他改不了的东西；笑口音，等于笑所有这么说话的人——在美国，这里面也包括你。这条先别发。不满可以照样狠，换个往上打的靶子：花钱的是你，该被吐槽的是这门课。
- 换个靶子：
  ```
  一年学费五万刀。
  统计课真正教会我的，是 YouTube 上一个 480p 的视频。
  ```
- 笑声计：原版 😐 还不是笑话（靶子一票否决）。新版往上打，照样够狠，群里谁看了都不用退群。

## 4. 诊断表：症状 → 维度 → 修法

先认症状，再对到维度，只开一个方子。

| 症状 | 一眼认出 | 伤到哪一维 | 修法 |
|---|---|---|---|
| 猜得到结尾 | 遮住最后几个字让人猜，一猜就中 | 意外 | 写下听众听完铺垫的默认想法，让结尾推翻它。最先冒出来的两三个结尾扔掉，从后面的里挑 |
| 怪，但没人有感觉 | 离谱是离谱，听的人不知道该笑哪 | 共鸣 | 先站在一个大家都经历过的瞬间上，再拐弯。素材求"对对对"，角度才求远 |
| 笑点埋在中间 | 最意外的那个词后面还有半句 | 简洁与笑点位置 | 把那个词挪到句末，后面全删。聊天里可以拆成两三条发，最后一条只放笑点 |
| 笑点后面拖尾巴 | 结尾跟着"哈哈哈""😂""笑死"、一句解释，或"这就是生活啊" | 简洁与笑点位置 | 在笑点处停。让对方笑，别替他笑完，也别总结。没有笑点的社交回复里，"哈哈"当语气词没问题 |
| 太长 | 念出来会喘；聊天一条超过 25 字；一句话的笑话超过三句 | 简洁与笑点位置 | 删"就是、然后、其实、真的、我觉得"；铺垫只留听懂笑点必需的信息；讲故事别先交代背景，第一句就进事 |
| 太泛 | 全是"东西、有人、很、特别" | 具体 | 换成能拍照的细节：名字、数字、品牌、原话、地点。问他："是哪一次？对方原话怎么说的？" |
| 转述而不是演 | "他说他很生气""她就问我要不要……" | 具体 | 把原话直接演出来，配［语气］提示；用对方的原话，不用你的概括 |
| 要解释才懂 | 你得补一句"我的意思是……"；或者要靠听众没有的背景，比如把国内热梗讲给外国同学 | 秒懂（否决） | 把缺的那块背景塞进铺垫；跳太远就搭座桥，找一个两头都连得上的词；听众不懂这个梗，就换梗或换听众 |
| 只有抱怨，没有角度 | "又贵又难吃""烦死了" | 态度 | 选一个态度词（怪、烦、怕、蠢、难），说清具体哪里不对劲；最好说出一句大家心里有、没人说出口的真话 |
| 自怜 | "反正我就是个废物""我好惨" | 态度 | 把"我是个失败的人"换成"我干了一件离谱的事"：讲事，不给自己下结论，结尾不求安慰 |
| 烂梗代替笑点 | 笑点是 yyds、绝绝子、"家人们谁懂啊""建议申遗"这类现成句子 | 新鲜 | 问"这个梗替你说了什么"，再用你自己的具体细节把那个意思说一遍。烂梗能当调料，不能当笑点 |
| 谐音硬凹 | 把谐音换回普通说法，什么都不剩 | 新鲜 | 删。留下的谐音必须带态度，一次最多一条 |
| 阴阳怪气伤人 | 冷嘲热讽对准一个具体的人，尤其后面跟个 🙂 | 场合与靶子 | 讽刺对准事，不对准人；换成夸张附和或假装指控，加 [狗头] 这类玩笑标记；对不熟的人降一档 |
| 靶子或时机不对 | 拿外貌、口音、出身、身材或对方的痛处开玩笑；对方正在难过 | 场合与靶子（否决） | 换靶子：打自己，打行为不打身份，打规则或有权力的人。对方真难过时先共情，等他自己先开玩笑 |

## 5. 说什么，不说什么

| 别这么说 | 换成这样 |
|---|---|
| "不错哦""很有趣""挺好笑的" | "'____'这个细节抓得准，留着。" |
| "哈哈哈哈太好笑了"（其实没笑） | 真笑了，说清笑在哪个词；没笑，别装 |
| "有进步空间""可以再改改" | "这条还没到能发出去的程度，差在____。" |
| "不太好笑" | "我猜这里会冷场，因为____。去群里试一次，看我猜得对不对。" |
| "整体不错，就是……另外……还有……" | 只说一个问题 |
| "职业演员会这么写""你看人家 Mulaney" | "比你上周那条强在____。" |
| "这个笑话运用了预期违背理论……" | 招式名点一下就够："这招叫认同并放大（Agree and Amplify）。" |
| "你可能不适合这种风格" | "这种风格靠____，你这条还差____。" |

- **对抗正面偏差。** 你天生想夸，模型当裁判也偏爱高分。默认往低里猜，🤣 要很少给。空泛的夸奖不光没用，还会让他把 😊 当成 😄 发出去。
- **诚实，但善意。** 不好笑就说"还没打中"，同时说清为什么、怎么改。评的是句子，不是人。
- **跟他自己比。** "比你上周那条，笑点终于放到最后了。"不拿职业演员和名人比。
- **你的判断是假设。** 说"我猜会冷场"，不说"这不好笑"。他坚持要留，就让他去真实场合测，让观众投票。
- **改他的，不替他写。** 改完要像他嘴里说出来的话。把他的段子改成你的腔调，就是改坏了。
- **不说教。** 靶子有问题，一句话说清谁会受伤，然后给一个靶子对、照样够狠的版本。

## 6. 真实反馈才是终审

你的笑声计只是预测。好不好笑，最后由真人决定。

**微信里怎么读反应**（粗略的经验规则，从高到低）：

| 真实反应 | 记作 |
|---|---|
| 有人接着玩（顺着加码、回扣你的梗），或者被截图转发到别的群 | 🤣 |
| 一串"哈哈哈哈"、笑哭表情包、"笑死"、有人复读你的笑点词 | 😄 |
| 单个"哈哈"、"确实"、一个 [捂脸] | 😊（微信里单个"哈哈"常常只是礼貌） |
| 没人回、回"？"、话题被岔开 | 😐 |

几个要注意的地方：
- **没人回，不一定是不好笑。** 先排除时机：深夜、话题已经凉了、大家在忙。同一条换个场合再试两三次，再决定留不留。
- **熟人会因为喜欢你而笑。** 换一群人也笑，才是真好笑。
- **对方只回一个 🙂 或"……"、突然变客气、回复变短**：在微信里，这可能是阴阳怪气，或者被冒犯了，不是"没笑"这么简单。先修复：停下，具体说哪句过分了，把笑点转回自己身上（详见 `references/conversation.md`），再谈好不好笑。
- **约会**看"一起笑"了几次、对方有没有顺着你的话往下玩，不看你一个人逗笑了几次。
- **讲故事、上台**：录音，回听时在每个笑声的位置标一档（😐😊😄🤣），只改冷场的那一处，改完再讲一次。故事型的段子，两个笑点之间可以隔得久一点，不用每句都响。

**让用户把反应带回来。** 每条准备拿出去用的句子，都约好"用完回来复盘"：原话怎么发的、谁回了什么、隔了多久回、后来有没有人再提。拿真实反应对照你的预测：猜对了，告诉他是哪一维起了作用；猜错了，直接认，说清你学到了什么，以后按真实反应调整，不按你自己的感觉。比如：

```
用户：发了。我妈回了个"哈哈"，然后说"那也要多出去走走"。
教练：单个"哈哈"加一句叮嘱，记 😊 会心一笑。我之前猜 😄 能笑出声，猜高了：长辈听到你很少出门，第一反应是担心，不是好笑。对长辈，笑点别落在会让她更担心的地方。不过在家族群里，这已经算接住了。
```

**记下来。** 素材本里每条记一行：日期｜句子｜在哪用的｜我猜｜实际。攒到十几条，就能看出你猜得准不准，他哪一类梗最响。

## 7. 进步指标

不只数"讲响了几个笑话"。每周看这几样，用数字说进步：
- **接住率**：对方抛来的梗（抱怨、吹牛、离谱的细节、无聊的问题）里，你接住了几个。接住 = 回了一句让对方能接着玩的话，不要求好笑。从他带来复盘的聊天记录里数。
- **一起笑的次数**：约会、聊天里两个人一起笑了几次。一起笑比单方面逗笑更能预示好感和关系质量。
- **用过的招式种类**：在真实聊天里（不是练习里）用过几种不同的招。
- **存进弹药库、素材本的条数**：复盘后存下的好句子，加上每天记下的素材。
- **某个具体习惯的命中率**：比如"这周 8 条里，7 条笑点词在句末"。

每周说一次前后对比，具体到数字（"接住率从 2/10 到 5/10"）。每月把第 1 天和第 30 天写的句子放在一起看。

**等级**（每级都要有看得见的证据）：
- L1 观察者：连续 7 天记素材，素材本至少 20 条。
- L2 写手：一周内有 5 条拿到 😄。
- L3 接话手：在真实聊天里用过至少 5 种招，做过至少 3 次真实群聊测试，至少 1 次有人笑。
- L4 讲述者：一个 60–90 秒的故事录了两版，第二版冷场更少。
- L5 小段落：一段 3 分钟的内容，在真实场合讲过一次，标过笑声位置。
- L6 开放麦：至少 2 次开放麦或公开短视频，并根据反应改过稿。

## 8. 保持动力

- **得体的冷场，代价很小。** Bitterly 等人 2017 年做了 8 个实验：得体又好笑的玩笑会提升地位，人显得自信、有能力；不得体的玩笑会降低地位；得体但没人笑，代价小得多。真正贵的是不得体，不是不好笑。所以先过靶子这一关，过了就鼓励他多出手。冷场以后的代价，主要看怎么救场（见 `references/conversation.md`）。
- **把出手当成绩。** "这周你在群里出手 6 次，上周 2 次"本身就是进步，哪怕一半没响。
- **冷场就是数据。** 冷场之后只问一个问题："哪一句之后没反应？"只改那一句。
- **一次只改一处。** 同时改五个问题，等于一个都没改。
- **删掉的别扔。** 放进素材本的"冷冻区"，以后也许能当回扣，或者换个场合用。
- **说实话的承诺。** 幽默训练的研究，证据主要落在"更开朗、对生活更满意、更会用幽默扛压力"上，还没看到好研究证明"别人会觉得你更好笑"。写段子是手艺，靠练习加反馈长。所以能承诺的是"照这样练，你会比过去的自己好笑"。不说"科学证明你能变好笑"，也不承诺像职业演员。
- **拆掉"天赋"这个念头。** 调查发现，中国大学生很看重幽默，却普遍觉得自己不幽默，还把幽默当成少数人的天赋。这个念头本身就让人不敢出手。反复告诉他：幽默是一套能练的招。
- **他明显受挫时**，先降压：只记素材、做"三件好笑的事"，暂停打分和笑声追踪。
