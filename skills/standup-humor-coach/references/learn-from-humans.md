# 向人类学习：偷结构，不偷段子

这份文件管三件事：怎么拆用户收藏的人类段子；联网搜索能搜到什么、搜不到什么；以及按风格推荐真人专场给用户看。

**目录**：1 什么时候读 ｜ 2 为什么要向人类学 ｜ 3 用户的笑点收藏夹 ｜ 4 联网搜索 ｜ 5 偷结构，不偷段子 ｜ 6 推荐看什么

## 1. 什么时候读这份文件

- 用户发来让他笑出声的段子、评论、视频截图或链接。
- 用户问"人类是怎么写这个的""有没有哪个演员讲过这个"。
- 你在段子工坊或大师拆解里，想先看看人类在同一个题材上找过哪些角度。
- 用户想找真人专场来看、来学。

## 2. 为什么要向人类学

- **AI 最缺"真人笑过"的信号。** 模型判断好不好笑不靠谱，第一念头又偏老套（见 `references/ai-humor-engine.md` 第 2 节）。点赞、弹幕、现场笑声、用户自己笑出声，都是真人投过的票。
- **用户自己的收藏最准。** A/B 只能在你写的两条里挑；他收藏的段子，是在全世界的段子里挑出来的，直接说明他吃哪一口。
- **人类给的是角度，不是答案。** 用户的事（"室友把空瓶放回冰箱"）网上不会有现成的段子。人类的例子能告诉你"这类事别人从哪切进去"，最后那句还得用他的细节现写。

## 3. 用户的笑点收藏夹

**怎么要**：一次要 3–5 个就够。"最近刷到、让你真的笑出声的段子、评论、视频片段，发我看看。文字、截图、链接都行，不用挑'高级'的。"截图你可以直接读；只有链接、又打不开的，请他把那句话打出来，或者描述一下那个片段。

**怎么拆**：每一个都用下面的模板，在回复里只写结论，不要全文转录原段子。

```
📌 收藏 #N：（一句话概括，不转录全文）
来源：谁 / 在哪
题材：……
角度：这个题材里，它挑了哪个别人没想到的点
机制：预期违背 / 文体错位 / 轻描淡写 / ……（名称见 references/toolbox.md）
笑点词：……
为什么戳中你：（问用户一句，他的回答比你的分析重要）
可移植的骨架：用一句话写出公式，比如"把 X 写成 Y 的官方文件"
```

拆完马上移植一次：用这个骨架，拿用户自己最近的一件事写一条。再请他用同一个骨架写一条，这一步不能省。

**怎么记进笑点档案**：
- 3 个以上收藏用了同一种机制，或者有同一种口吻（比如都靠暗示、都很冷），写进档案的"偏爱"。
- 收藏比 A/B 选择分量重：一个收藏抵得上两三次 A/B。
- 他收藏里很少出现的东西（比如从没有谐音梗、从没有网络烂梗），是"不吃"的有力证据。
- 档案模板和更新规则在 `references/taste-calibration.md` 第 6 节。

**怎么用**：给他写示范时，拿收藏当风格参照：同样的口吻、同样的留白程度、同样的长度。不要照抄句子，也不要直接套用原段子的笑点。

## 4. 联网搜索

**能搜什么**：
- 这个题材有没有演员、节目、网友写过：比如"留学生 + 单口喜剧""某个演员 + 某个题材"。
- 演员的风格介绍、访谈、评论文章：可以从中提炼手法。
- 可以推荐给用户去看的专场、剧集、节目。

**搜不到或靠不住的**：
- **段子原文**：搜索结果一般只给摘要和评论，不会原样给出喜剧内容；字幕和文字稿也常常打不开。
- **知乎高赞、微博神评论、B 站弹幕**：通用搜索很少能直接搜到具体的回答和评论，搜出来常是无关文章，甚至广告。这类内容最好请用户自己截图发来。
- **"XX 笑话大全""搞笑段子合集"**：多是库存梗和谐音梗，正是幽默引擎要封杀的东西。可以当反例给用户看，不要当参考。
- 有的环境不能联网，或者网页打不开（比如被网络策略拦住）。搜不到就直说，改用用户的收藏夹和你自己的引擎，不要编"某某演员讲过……"。

**怎么搜**：
- 中文：`<演员> <题材> 脱口秀`、`<题材> 脱口秀 段子 角度`、`留学生 单口喜剧`。
- 英文：`stand-up <topic> bit`、`<comedian> <topic> special`、`international student comedian`。
- 一个题材搜一两次就停。没有就算了，搜索不是这个 skill 的主菜。

**怎么用结果**：提炼"别人从哪个角度切的、用了什么机制"，然后回到幽默引擎，用用户自己的细节现写。想给用户看出处，就说"这个题材 X 也讲过，可以去看"，附上链接。

## 5. 偷结构，不偷段子

- **结构是公共的，段子是别人的。** "把小事写成刑事案件通报"是结构，谁都能用；某个演员的某一段，是他的作品。
- **引用最多一两句，注明是谁的。** 拆解时用转述，不全文转录。
- **不把别人的段子包装成用户的素材**，也不建议他在聚会、约会、台上讲别人的段子。在脱口秀圈，偷段子是最重的罪名；放到生活里，讲一个大家都看过的段子，只会换来"这个我看过"。
- **不编造。** 不确定某个演员有没有讲过某个题材，就不要说他讲过。说"他常用的手法是……"，而不是"他有一段讲……"。

## 6. 推荐看什么

按用户喜欢的风格，给他列两三个就够，别一次甩一长串。看的时候让他带着一个问题看："他的笑点词都放在哪？""他是怎么开场的？"看完回来，挑一段最喜欢的，走第 3 节的拆解。

| 风格 | 推荐 |
|---|---|
| 观察吐槽 | Jerry Seinfeld《23 Hours to Kill》；Nate Bargatze《The Tennessee Kid》《Hello World》 |
| 自嘲讲故事 | John Mulaney《Kid Gorgeous at Radio City》；Hasan Minhaj《Homecoming King》；Mike Birbiglia《Thank God for Jokes》 |
| 犀利敢说 | Chris Rock《Tamborine》；Bill Burr《Paper Tiger》；Dave Chappelle《Killin' Them Softly》 |
| 留学生、亚裔视角（最容易有共鸣） | Ronny Chieng 的剧集《International Student》（按他在墨尔本留学的经历改编）和专场《Asian Comedian Destroys America!》；Jimmy O. Yang《Good Deal》；Ali Wong《Baby Cobra》 |
| 中文 | 《脱口秀大会》《喜剧之王单口季》里的周奇墨、鸟鸟、何广智、徐志胜、呼兰；线下可以去当地的中文开放麦看新人怎么磨段子 |

有些专场里有不少粗口和成人内容，推荐时提一句。平台和上架情况会变，用户问"在哪看"，能搜就搜一下，不能搜就让他自己查。
