# 讲故事：把好笑的事讲好笑

> 写给用户的长度，以 SKILL.md 开头的“回复要短”为准：这里的流程和清单是你心里走的，给用户的只有结果，默认 150 字以内。

这份文件专治"好笑的事一讲就平"：怎么诊断，怎么改结构，怎么把转述演成场景，怎么按群聊、约会、上台出不同版本。

文中示例只用来理解机制；给用户做示范时，用用户自己的素材现写，不要原样复用。

标记：换行或"／"＝停一拍；［ ］＝表演提示（语气、动作）；【 】＝内心独白（心里想的，没说出口）。

## 1. 什么时候读这份文件

- 段子工坊模式：用户讲了一件事想讲得好笑，要准备聚会、约会或上台讲的故事，或者说"好笑的事一讲就平"。你自己写故事型示范之前也读。
- 改一个故事的顺序：第 2 节诊断 → 第 3 节先修最大的问题 → 第 4 节搭骨架 → 第 5 节把转述换成场景 → 第 8 节按场合出版本。
- 单句笑话的技法看 `references/toolbox.md`；接梗和约会分寸看 `references/conversation.md`；没东西可讲，先去 `references/drills.md` 挖素材。

## 2. 故事为什么平

平的故事，通常缺下面两样之一。

### 原因一：没说"我想要什么"（利害 stakes）

听的人不知道你想要什么，就不知道该替你紧张什么；没有紧张，笑点就没有东西可以释放。面子也算利害，对留学生来说常常是最大的那个。
试金石：能补上"我想要＿＿，因为＿＿"吗？补不出来，先别讲。

- 平："我去 office hour 问了一下成绩。"
- 有利害："我必须让教授把 B+ 改成 A-，因为我已经跟我爸说了我全是 A。我准备了十分钟的论证，还打印了出来。教授看完，沉默了很久：'Actually... this should be a B.'／全校大概只有我，去 office hour 被砍了价。"

### 原因二：没有"变的那一刻"（五秒钟时刻 five-second moment）

没有变化的只是一件事（anecdote），不是故事。变化可以很小：一个想法、一个决定、一次认怂。整个故事都为那几秒服务，跟那几秒无关的都可以删。喜剧里最好用的变化是"意识到了，但还是没改掉"。
试金石：这件事之后，你哪里不一样了？

- 变之前："开学第一周，我跟所有人宣布：我不起英文名。名字是爸妈给的，是根。"
- 那五秒："第三周，教授第三次把 Xu Qi 念成 Sushi。全班回头找人。我在座位上挣扎了五秒钟，／举起了手。"
- 变之后："我爸到现在都不知道，他翻了三天字典给我起的名字，在美国是一道菜。"

### 快速诊断

| 症状 | 听起来像 | 先修哪里 |
|---|---|---|
| 流水账 | "然后……然后……然后……" | 第 3 节修法 1 |
| 铺垫太长 | 从早上出门讲起，一分钟了还没出事 | 第 4 节：从第一个不对劲开讲 |
| 先剧透 | "笑死我了我跟你说""我那天太倒霉了" | 删掉，第一句直接进场 |
| 笑点埋在中间 | 最好笑的词后面还拖着半句，或者跟一句"你敢信吗" | 第 3 节修法 3 |
| 转述而不是演 | "她问了我一些问题，我就都说 yes" | 第 5 节：表演、内心独白 |
| 细节太泛 | "很贵""好多人""超尴尬" | 第 5 节：具体化 |
| 作文腔 | "那是一个寒风刺骨的夜晚" | 晚餐测试：饭桌上不会说的词全删 |
| 结尾在总结 | "反正挺好笑的""所以我现在都……""那天我明白了……" | 换成最后一拍，或回扣开头 |
| 故事太安全 | 讲来讲去其实是"我多厉害" | 换一个你有点不想讲的：丢脸但不伤人、已经过去了的 |

## 3. 三个最快的修法

### 修法 1：把"然后"换成"但是 / 所以"（but / therefore）

"然后"只交代顺序，听的人没理由在乎下一句。"但是"制造阻碍，"所以"带出后果，两个交替着用，故事自己就往前走。
做法：把故事写成 5 个要点，两点之间只许填"但是"或"所以"。只能填"然后"的地方，删掉，或者改成有阻碍、有因果的事。

- 然后版："我去超市买了鸡蛋，然后回家路上摔了一跤，然后鸡蛋碎了，然后就做了个荷包蛋。"
- 但是/所以版："我请三个朋友来家里吃饭，想证明我会做饭，所以买了最贵的有机鸡蛋。但是回家路上我在冰上摔了一跤，十二个碎了十一个。所以那晚的大餐只有一道菜：一个荷包蛋，四个人分。／我们切得特别小心，像在分遗产。"

别每句都硬接"但是"，那是绕口令。"所以"后面的结果要一次比一次大。

### 修法 2：先定结尾，倒着搭（begin with the ending）

"讲着讲着就没了"，是因为没有落点。Mike Birbiglia 和 Matthew Dicks 都是先有最后一句，再往回搭。先写最后一句，再问：要让这句成立，听的人必须提前知道什么？只留这些，然后把开头挪到第一个"不对劲"出现的地方。

- 先定结尾："海关那条小猎犬看着我，眼神特别温柔，像在说：你妈塞的吧。"
- 倒推需要：①箱子里有腊肠；②我不知道；③出发前我妈说"放心，不会查的"。
- 开头直接从狗开始："我一落地，一条小猎犬已经坐在我箱子旁边了，一动不动，像在等我自首。"
- 删掉："那天早上六点，我爸开车送我去浦东……"

### 修法 3：最好笑的词放最后（punch word last）

笑声在意思揭晓的那一下出来。关键词后面还拖着半句，笑就被压住了。中文习惯先说结论，要刻意反着说：用"结果……"、破折号，或者干脆单独成句，把揭底的词推到最后，说完就闭嘴。

- ❌ "一个三岁小孩帮我翻译了我第一次用英语点的餐。"
- ✅ "我第一次用英语点餐，说了很长一段，很流利。店员没听懂。旁边一个小孩帮我翻译了。／他三岁。"

自检：遮住最后两三个字，这句还好笑吗？还好笑，说明笑点不在最后。

## 4. 故事骨架

**想要 → 障碍 / 硬撑 → 升级 ×3 → 反转 / 变化 → 收尾（最好回扣开头）**

- **想要**：前 15 秒说清你想要什么（利害）。
- **障碍 / 硬撑**：什么挡着你，你又怎么硬撑着不认输。硬撑是自嘲的燃料：明明没听懂，还在说 yes。
- **升级 ×3**：同一类事来三次，一次比一次离谱，第三次跳级或掉头（三段式 rule of three）。相声的三翻四抖是同一个道理：铺三次，第四次抖响，见 `references/chinese-comedy.md`。节奏越来越快，最后一拍前停一下。
- **反转 / 变化**：五秒钟时刻。到这里放慢（见下面的沙漏）。
- **收尾（button）**：最后一拍，说完就停。最好把开头的一个词或画面换个意思再用一次（回扣 callback）。也可以在开头若无其事地埋一个细节，到这里收回来：第 8 节上台版里的"五楼一半是中国留学生"就是埋的。

**从尽量靠近结尾的地方开讲**（start as close to the end as possible）。第一句＝我＋在哪＋在干嘛＋一个不对劲的细节。不寒暄，不预告"这个超好笑"：预告会抬高期待，还会提前用掉惊喜。

- ❌ "我跟你说个事，笑死我了，就是我们学校那个……"
- ✅ "我人生第一次被美国警察拦下来，是因为我骑自行车太慢。"

**60 秒时间轴**（饭局、约会、短视频都能用）

| 时间 | 放什么 |
|---|---|
| 0–10 秒 | 第一句进场＋大象 |
| 10–25 秒 | 背包（你的计划）＋一个"但是" |
| 25–45 秒 | 升级，夹一句内心独白或一句表演 |
| 45–55 秒 | 揭晓＋收尾 |
| 55–60 秒 | 聊天、约会时，把话轮交回去（第 8 节） |

**最好用的几个故事工具**（出自 Matthew Dicks《Storyworthy》，只留 60 秒口头故事用得上的）

- **利害（stakes）**：想要什么、为什么要紧、什么挡着。一句就够："我已经跟我爸说了我全是 A。"
- **大象（the Elephant）**：前三句内亮出这个故事要解决的问题，听的人才知道自己在等什么。"我面前两个选择：承认我没听懂，或者第十二次说 'Yeah, totally'。"（后来：第十二次之后，我答应了周六帮他搬家。搬到另一个州。）
- **背包（backpack）**：出事之前，先把你的计划交给听的人背着；计划越具体，落空越好笑。"打工面试前，我背了三十个答案。经理坐下第一句：'So... do you like dogs?'／我的三十个答案里，没有狗。"
- **面包屑（breadcrumbs）**：先漏一个奇怪的后果，不说原因，让人追着问"然后呢"。"那天下午，图书馆五楼所有人都认识了我奶奶。"
- **沙漏（hourglass）**：揭晓前故意放慢，用 3–5 个短句把那几秒拉长；揭晓句本身要短。"我点开期中成绩。页面在转圈。转第一圈，我想起我妈说'尽力就好'。转第二圈，我想起我没尽力。／平均分 68。我的分数，正好是平均分的一半。"
- **水晶球（crystal ball）**：先说一个预测，再让现实用更离谱、更具体的方式超过它。"表白前我想，最坏不就是被拒绝吗。／她没拒绝我。她把我介绍给她男朋友，说我人特别好，可以帮他改论文。"

**交稿前自检**（给用户看任何故事型示范之前）：第一句进场了吗？说了"想要"吗？有"但是"吗？有原话或内心独白吗？每个笑点词都在句末吗？最后一句是收尾，还是总结？

## 5. 把转述变成场景

转述是"我告诉你发生了什么"，场景是"你自己看见了"。下面五招把前者变成后者。

### 表演（act-out）

一句话：不说"考官很紧张"，直接变成考官，把他的话和动作演出来。
怎么做：①所有"他说""她问"改成原话。②每个角色给一个记号：一个声音特征＋一个动作＋一个朝向，转头就换人。③台词自己带出笑点，你不评论。
例：
- 转述："考驾照的时候，考官全程很严肃，我特别紧张，最后没过。"
- 演出："一路上，考官只说了三个词。［低沉，不看我］'Left.'……'Right.'……［右手慢慢握住车门上方的扶手］'Stop.'／回到考场，他在表上写了很久，抬头看着我：'Is there someone who can drive you home?'"

坑：边演边解释（"他就是那种人……"）；角色之间没区别，分不清谁在说话；演一半不好意思，半心半意比不演还尴尬。纯文字聊天演不了，用截图、照片、表情包代替。

### 内心独白（inner monologue）

一句话：把嘴上说的和心里想的并排摆出来，中间的落差就是笑点。John Mulaney 讲故事时常这样：讲到一半停下来，冷静地评价自己当时在想什么。
怎么做：①找到你"表面很镇定"的那一刻。②写出当时真正的想法，越具体、越小气越好。③讲的时候换个音量或转个头，让人听得出"这句是想的"。留学生有现成的素材：外语嘴，中文脑。嘴上一句 "Sounds good!"，脑子里是一整段中文弹幕。
例：
- 平："同学问我周末干嘛了，我随便应付了一句，其实啥也没干。"
- 改："同学问：'What did you do this weekend?' 我说：'Oh, just chilling.'／【其实我整个周末都在 YouTube 上学，怎么回答 what did you do this weekend。】"
- 再一例：嘴上："No worries, go ahead!" 心里：【微波炉是我先排的。你热的是一整只鸡。】

坑：独白太长，成了散文；"想的"没比"说的"更有料，只是换了个说法；约会时内心戏拿自己开涮，别拿来刻薄对方。

### 放大你的反应（exaggerate your reaction）

一句话：事可以很小，你的反应要大到荒诞。这是夸张升级（exaggeration / heightening）用在你自己身上：夸大的是反应，不是事实。
怎么做：写下真实的反应 → 放大十倍 → 落到一个能拍下来的动作或决定上。"我当时都崩溃了"是形容词，不是画面。
例：
- 平："房东说这个月房租可以晚两天交，我挺感动的。"
- 改："房东说房租可以晚两天交。我当场眼眶就红了。我在家被我妈骂了二十年，没哭过；在美国，一个中年男人宽限了我两天，／我差点管他叫爸。"

坑：夸大的是事件而不是反应，就滑向撒谎了（第 9 节）；约会时别把夸张的反应演成情绪不稳定。

### 具体化（specificity）

一句话：删掉通用细节，留下具体到有点怪的：数字、品牌、原话、颜色。怪的具体细节本身就是一个小笑点。
怎么做：每个细节问两句。删掉它，结尾还成立吗？成立又不好笑，就删。留下的能拍下来吗？拍不下来，就换成一个数字或名词。
例：
- 平："我打工的奶茶店老板特别抠。"
- 改："我打工的奶茶店，老板规定一杯珍珠放 38 颗，他说他数过。有个顾客投诉珍珠太少，老板当场把那杯倒进托盘，一颗一颗数给他看。／37 颗。／老板慢慢转过头，看着我。"

坑：具体不等于冗长，一口气列五个品牌就成了清单；别删掉后面要回扣的那个细节。

### 拿自己开刀（self-deprecation）

一句话：让你自己当笑点：本事不够、想太多、计划失败了还硬撑。你在低位，大家才笑得放心。
怎么做：看看故事里是谁出了丑。是别人的话，试着换成你，或者把你也算进去。嘲笑处境和能力，不嘲笑人格和价值。
例：
- 平（笑别人）："我们组那几个美国同学，做 presentation 根本不给我说话的机会。"
- 改（笑自己）："小组四个人，只有我母语不是英语。大家都特别照顾我——／给我分了'Thank you'那一页。"

坑：自嘲变自虐（"我就是个废物"），听的人会尴尬，不知道怎么接；"安全的自嘲"其实是变相炫耀（"我就是太认真了"）；约会时只笑处境和技能，不贬低自己的价值。

## 6. 段子结构（上台用）

**前提（premise）→ 例子（examples）→ 表演（act-out）→ 追加笑点（tags）→ 收尾（button）**

- **前提**：一句带态度（attitude）的观点，常用"＿＿很怪 / 很难 / 很可怕 / 很蠢，因为＿＿"。"美国超市很大"只是事实，不是前提。
- **例子**：2–3 个具体的例子，按离谱程度排。
- **表演**：挑最适合演的那个例子，演出来。
- **追加笑点**：笑点落地后不换场景，原地再拧一两圈：后果是什么？别人什么反应？最极端到哪？最强的放最后。写法见 `references/toolbox.md`。
- **收尾**：一句短的，说完就停；能回扣前提最好。

例（约 70 秒）：

| 段落 | 讲的话 |
|---|---|
| 前提 | "这个世界上最了解我的，不是我妈，是外卖 app。" |
| 例子 | "它知道我几点饿：凌晨一点，首页准时弹出'夜宵'。它知道我穷：一到月底，推荐页全是'满 20 减 15'。它还知道我分手了：以前我天天点双人套餐，上个月开始，首页写着：'一人食，也要好好吃饭。'" |
| 表演 | "最尴尬的是外卖小哥。他给我送了半年，那天把袋子递过来，停了一下：［上下打量，压低声音］'兄弟……今天还是一份啊？'／我说是。他点点头，从车筐里多抓了一双筷子塞给我：'拿着，显得热闹。'" |
| 追加笑点 | "第二天，我在备注里写：不用多给筷子。／他给了三双。" |
| 收尾 | "我妈到现在都不知道我分手了。／我们这一片的外卖小哥，已经开始给我介绍对象了。" |

批注：三个例子是三段式，第三个（分手）跳到了感情；小哥一句台词就立起一个人物；"三双"在同一个画面上再拧一圈；收尾回扣前提里的"我妈"，同时再升一级。

**开场和收尾**

- 开场：用最短、最稳、15–30 秒内能拿到第一个笑的段子，先让观众相信"这个人是好笑的"。自我介绍式的一句很好用（例见第 7 节）。
- 收尾：最强、最稳的段子放最后，最好回扣开场的一个词。看到亮灯就直接跳到收尾，绝不超时。
- 段落之间：新手不用硬串场，干净地换话题就好；熟练以后再用回扣把段落串起来。

**笑点密度（laughs per minute）**

- 常见说法：俱乐部脱口秀每分钟要有 4–6 次笑。
- 有争议：讲故事型的演员（比如 Hasan Minhaj）明确不认同固定频率，认为最深的笑来自几分钟的铺垫。
- 实用折中：①开头 15–30 秒内一定要有第一个笑；②之后可以蓄力，前提是张力在涨（利害在变大、面包屑还没收回）；③任何 20–30 秒既没笑、张力也没涨的段落，删或改。
- 怎么查：录音 → 转文字 → 按时间标出（笑）（小笑）→ 找出"无笑区" → 用内心独白、表演、具体化、追加笑点去补。例：第 4 节大象那个故事，"0:12–0:42 交代他是谁、我们怎么认识的"，30 秒没笑。压成一句，再加一句内心独白："他说了一长串，我只听懂了 Saturday。【问题不大，周六我有空。】"
- 坑：为了密度硬塞无关的笑话，把故事线打断；在情感最高点硬塞笑点，把五秒钟时刻冲淡。

## 7. 表演与节奏

- **停顿（pause / timing）**：揭晓前停一拍（稿子里标"／"）。笑点词放在最后（修法 3），说清楚，别加速；说完闭嘴，眼神停住；等笑声开始往下落，再接追加笑点，别踩着笑声说话。每句都停，等于没停。停顿是工具，不是规矩：日常聊天里停得太刻意，反而像在预告"包袱来了"；台上停一拍更常见。相声讲的"气口""尺寸"是一回事，见 `references/chinese-comedy.md`。
- **别在铺垫时自己笑**：你先笑，等于提前通知大家包袱要来了。想笑，等包袱落地、别人笑了再跟着笑。
  - ❌ "哈哈哈我跟你说，哈哈，我那个点餐……一个小孩……哈哈哈……"
  - ✅ ［平静，甚至有点委屈］"店员没听懂。旁边一个小孩帮我翻译了。"／"他三岁。"［低头喝口水］
- **全情投入（commit）**：讲的时候当真，这件事在当时对你很严重。一本正经（deadpan）地讲一件荒诞的事，本身就是反差。不笑场不等于冷着脸，是投入到当时的情绪里。表演要做完整，哪怕只是一个转头。
- **声音和语速**：叙述部分用饭桌上跟朋友聊天的音量和语速，像聊天，不像朗诵（晚餐测试 dinner test）。像聊天是设计出来的：结构精修，语气随意。角色靠一个声音特征区分：高一点、慢一点、带点口音。揭晓前放慢，揭晓句要短。叙述用中文、台词保留英文，是留学生天然的表演，前提是听的人听得懂。
- **冷场和翻车**：沉默是正常节奏，平静地往下讲；或者用一句提前准备好的救场句（saver），一场最多一次。绝不解释（"就是说，因为他才三岁……"），不道歉，不怪观众；冷场后别加速，别变小声。
  - 台上："好，这个笑话我回家再跟它谈谈。"
  - 饭局："嗯……这个故事在我心里是五星的。"
- **录音，标笑声**：每次讲都录（手机放口袋里就行；会录到别人的话，先打招呼）。回听，转文字，标出哪里笑了。只有真人的笑声能告诉你哪里好笑。Mike Birbiglia 的做法是一个故事先讲四五遍、听录音找笑点，再动笔写稿。
- **一次只改一处**：同时改五处，你不知道是哪一处起的作用。例（第 10 节的理发故事）：第 1 次讲，只有结尾有笑 → 加一句内心独白"一号是光头吗"，多一个笑 → 在 "You sure?" 前停一拍，最大的笑挪到了这里 → 把小费挪到后面当追加笑点，又多一个笑。
- **背熟第一句和最后一句**（The Moth 的建议），笑点句逐字定稿；中间只记 3–5 个关键词，连接的话现场说。整篇背下来，听起来像背课文。

**新手开放麦（open mic）**

- 30 秒内拿到第一个笑：开场用最短最稳的那个。
  - ❌ "大家好，我第一次上台，有点紧张，讲得不好大家多包涵……"
  - ✅ "大家好，我叫徐琦。在美国，大家叫我 Sushi。"（第 2 节的名字故事，压成了一句）
- 不道歉，不说"我第一次上台"：这会把观众推进同情模式，不是笑模式。
- 开放麦通常只给几分钟。只带 2–3 个最强的段落，宁可短而满；看到亮灯就进收尾。
- 节目单只写关键词，写在纸条或手背上；忘词就看一眼，直接跳下一段。
- 新段子夹在两个稳的段子中间测。
- 每场都录，回去只改一处。

## 8. 三种版本：群聊、约会、上台

同一个故事，换个场合，长度、停顿和表演都要跟着换。反应慢的人尤其该提前备好 3–5 个 60 秒故事，每个配一两个追加笑点和一个交回话轮的问题；聊到相关话题就拿出来，这就是随时能用的"即兴"。

| | 群聊版 | 约会版 | 上台版 |
|---|---|---|---|
| 长度 | 一个笑点 3–5 条；完整故事 8–12 条 | 约 60 秒（口语 200 字左右）；刚认识、还在热身时先讲 30 秒版：一个"想要"、一次升级、揭晓 | 60–90 秒 |
| 停顿靠 | 分条发；揭晓的词单独一条，发之前等两三秒 | 揭晓前一个小停顿 | 停一拍，等笑声落下再接 |
| 表演靠 | 截图、照片、表情包、"我爸：……"的对话体 | 一个语气、一个表情，幅度小 | 声音＋动作＋朝向，放开演 |
| 删掉 | 背景交代、旁白、长内心独白 | 太长的交代；连着讲"我有多惨" | 只删既不好笑、也不推进的 |
| 结尾 | 揭晓那条之后闭嘴，别人笑了再补一条追加笑点 | 用一个对方好接的问题把话轮交回去 | 收尾＋回扣开头 |

几条硬规矩：
- 群聊：第一条是钩子（大象或面包屑），不是"笑死"；不发文字墙，不发 60 秒语音方阵；揭晓之后不补"哈哈哈"，不发笑哭，不解释；有长辈的群，英文台词少用。
- 约会：故事是递过去的话头，不是独角戏。对方接着讲他自己的事，你就当好观众（见 `references/conversation.md`）。

### 示范：同一个故事，三个版本

用户原话："我今天在图书馆静音区，耳机没连上，点开家族群语音直接外放了，全楼都听见了，超尴尬。"

**群聊版**（每行一条）

```text
今天下午，图书馆五楼所有人都认识了我奶奶
五楼是静音层
我耳机没连上，点开了家族群的语音
外放
我爸：儿子！豆豆会握手了！
我去按暂停，按成了下一条
我妈：别听你爸的，那是抽筋
下一条自己开始播了
我奶奶：乖孙，在图书馆吧？
要安静啊
```

等大家笑了，再补两条："斜对面的美国哥们摘下耳机，冲我点了点头""他一个字没听懂，但他同意我奶奶"

**约会版**（约 60 秒）

> 上周我在图书馆五楼，就是那种翻书都不敢翻出声的静音层，点开了家族群的语音。耳机没连上。
> 我爸的声音直接冲出来：［稍大声］"儿子！豆豆会握手了！"
> 我去按暂停，手一抖，按成了下一条。我妈："别听你爸的，那是抽筋。"
> 然后它自己开始播下一条。我奶奶，［慢、慈祥］"乖孙，在图书馆吧？／要安静啊。"
> 整层楼都抬头看我。斜对面一个美国男生摘下耳机，冲我点了点头。他一个字没听懂，／但他完全同意。
>
> （交回话轮）"你们家群里，谁最爱发语音？"

**上台版**（约 80 秒）

> 我们学校图书馆五楼是静音层。安静到什么程度？大家翻书，都挑同一个时间翻。五楼一半是中国留学生。
> 那天我只有一个目标：当一个不存在的人，把 essay 写完。晚上十二点 due。
> 我点开了家族群的语音。／耳机没连上。
> ［突然大声，学我爸］"儿子！豆豆会握手了！"
> 【只要我不动，他们就不知道是我。】
> ［疯狂戳屏幕］我去按暂停，按成了下一条。
> ［学我妈，嫌弃］"别听你爸的，那是抽筋。"
> 微信有个功能：没听过的语音，会自动连着播。
> ［学我奶奶，慢、慈祥］"乖孙啊，在图书馆吧？／要安静啊。"
> 整层楼抬起头。斜对面一个美国男生摘下耳机，看着我，点了点头。／他一个字没听懂，但他完全同意。
> 那天 essay 写得特别快。三个小时，我一次都没敢抬头。
> 我本来只想当一个不存在的人。／现在五楼一半的人，管我叫乖孙。

变了什么：
- 群聊：开头换成面包屑；一人一句台词，各占一条；奶奶那句拆开，"要安静啊"单独发；没有旁白。
- 约会：加回"静音层"的画面，让对方看得见；三个人的声音只做一点区别；加一个追加笑点（美国男生）；最后问对方家里的群，对方一定有话说。
- 上台：前 15 秒补上利害（当一个不存在的人，十二点 due）；提前埋下"五楼一半是中国留学生"；加内心独白和更大的表演；两个追加笑点；收尾同时回扣"不存在的人"和埋下的那一句。

## 9. 真实的底线

- **可以夸大程度**：你的反应、比喻、感受，和一听就知道是夸张的数字。听的人默认讲故事有加工。
- **可以剪裁**：压缩时间、删掉无关的人、调整顺序。
- **不编造事实**：没发生的事，不讲成"我身上发生的"。纯段子可以虚构，但别声称是真事。约会时编的故事，以后都要还。
- **绝不给真实的人编指控**：室友、前任、教授、同学、家人，没做过的事一件都不能安到他们头上。群聊会被截图转发，涉及真人的故事，去掉能认出身份的细节。
- **前车之鉴**：以讲个人故事出名的 Hasan Minhaj，2023 年被媒体核实出几段"亲身经历"有虚构成分，争议很大，也付出了职业代价。观众听到"这是我身上发生的"，就默认它是真的。
- 想走犀利路线，矛头对准自己、观念或有权力的人，不对准能被认出来的普通人（见 `references/styles.md`）。

## 10. 完整改写示范：理发

演示机制用。用户的故事如果也是"一路 yes 到底"型（点餐、开户、办手续），只借结构，台词和结尾用他自己的细节现写。

**原版（很平）**

> 上周我去学校旁边的理发店剪头发。美国剪头发挺贵的，剪一次三十多刀，还要给小费。理发师问了我一些问题，我没太听懂，就都说 yes。结果她给我剪得特别短，两边都推没了。回去室友还笑我。过了两个月才长回来。所以我现在都去华人理发店了。

**诊断**

- 没有想要：这次理发为什么要紧？→ 周五有个约会。
- 没有五秒钟时刻：照镜子那一刻一笔带过 → 放慢。
- "问了我一些问题"是转述 → 原话演出来；没听懂时在想什么？→ 内心独白。
- 价格放在开头，成了交代 → 挪到后面当追加笑点。
- 结尾是一条生活建议 → 换成回扣 yes。

**先定结尾**：约会对象问"你是当兵的吗？"，我又说了 yes。变化是"意识到了，但还是没改掉"。前面所有铺垫都为这一句服务。

**60 秒口头版**

| 讲的话 | 批注 |
|---|---|
| 我在美国学到的最贵的一个英语单词，是 yes。 | 面包屑＋大象：只说"最贵"，不说为什么；笑点词放句末 |
| 周五我有个约会，所以周三去剪头发。进门前我背好了一句：Just a little trim, please. | 利害＋背包 |
| 我没机会说。 | 但是：计划第一秒就落空 |
| 理发师手里已经拿着推子：［快、平］"Number two on the sides?" | 表演：原话，不转述 |
| 【二号？一号应该是光头吧。那二号还行。】［很自信］"Yes." | 内心独白：外语嘴，中文脑 |
| "Take the top down too?" "Yes." "Clean up the neck?" "Yes." | 三段式，节奏越来越快 |
| 她停下来，从镜子里看着我：／"……You sure?" | 第四拍变向（三翻四抖）；停顿 |
| 理发师问你"你确定吗"的时候，你应该起身就跑。／我说："Yes." | 先给忠告，再亲自违反：自嘲 |
| 嗡——。十分钟后，她举起镜子。／我这辈子第一次，这么完整地见到我的耳朵。 | 沙漏：五秒钟时刻放慢；具体化代替"剪得很短" |
| 我付了三十五刀，又加了 20% 小费——／给一个把我剪成这样的人。 | 价格挪到这里当追加笑点；笑点词最后 |
| 周五见面，她第一句话是："Oh wow... are you in the military?" | 回到开头的利害 |
| 我张了张嘴，／听见自己说：［认命］"……Yes." | 收尾＋回扣：意识到了，还是没改掉 |

约会时讲完，交回话轮："你有没有那种明明没听懂，还一路 yes 到底的时候？"

**群聊版**（每行一条）

```text
我在美国学到最贵的一个英语单词：yes
周三剪头发，理发师问 number two on the sides?
我不知道二号是啥，但听着不像光头
yes
top down too? yes
clean up the neck? yes
她停下来看着我：you sure?
yes
[照片：后脑勺，两只耳朵全露]
还给了 20% 小费
周五约会，她见我第一句：are you in the military?
yes
```

批注：yes 单独成条，一眼看去就是三段式；照片代替"见到我的耳朵"那句表演；最后一条发之前停两三秒，只发 yes，后面什么都不加。背包和"应该起身就跑"的旁白都删了，群聊里旁白越少越好。

**上台版：接在最后的追加笑点**

> 那天晚上我妈视频，看见我愣了三秒："你们美国大学也军训啊？"
> 我爸凑过来看了一眼："挺好，精神。"／他跟我提了二十年的发型，最后是一个美国理发师帮他办成的。
