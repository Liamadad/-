## 1. 什么时候读这份文件

聊天复盘、实战陪练时读。用户说"反应慢""好回复总是事后才想到""怕说错""又把天聊死了"，或者问群聊、约会、调侃的分寸、冷场怎么办时，也读这份。治反应慢，先看第 2、3、5 节；陪练群聊和约会，看第 6、7、8 节。

文中示例只用来理解机制；给用户做示范时，用用户自己的素材现写，不要原样复用。

## 2. 先把目标降下来

聊天不是开放麦。目标不是"说出一句妙语"，而是**接住，再加一点**：让对方知道这个球有人接，而且还能接着玩。

**最低回复公式：重复关键词 + 情绪 + 一个具体细节。**

- 朋友：「我今天在宜家逛了五个小时。」→「五个小时？？午饭是在里面吃的肉丸吧。」

这算不上妙语，但球接住了，对方会接着往下说。反应慢的人先把这一招用熟。

**零门槛起步：当捧哏。** 你不负责抖包袱，只负责让别人的包袱响：①追问一个能引出笑点的细节；②把对方最好笑的那个词重复一遍；③补一句很短的追加笑点（tag），然后把话头还给他。

- A：「今天 office hour 跟教授聊了二十分钟，出来才发现拉链没拉。」
- 你：「二十分钟？？教授全程什么表情？」
- A：「他全程特别认真地看着我的眼睛。」
- 你：「……他在保护你。」

别抢故事（"我也是！我那次更惨……"），也别只回"哈哈哈"，那等于没给对方任何能接的东西。

**为什么可以把目标降下来：**

- 对话里的笑，大多不是笑话引起的：笑声前的那句话，只有一到两成算得上好笑（Provine，2000）。笑首先是"我们处得不错"的信号。
- 一起笑比把人逗笑重要：陌生人聊十来分钟，两人同时笑和双方的约会兴趣相关（Hall，2015）；情侣一起笑的比例，能单独预测关系质量（Kurtz、Algoe，2015）。
- 失手便宜，冒犯才贵：不得体的玩笑会降低别人对你的评价；得体但没人笑，代价小得多（Bitterly 等，2017）。
- 觉得自己"没幽默细胞"很常见：中国大学生普遍很看重幽默，却给自己打低分，还容易把幽默看成少数人的天赋（岳晓东，2008；Yue 等，2016）。其实它是一组能练的招式。

## 3. 触发情境 → 招式 速查表

反应慢的人缺的不是脑子，是提前装好的模式。听到一句话，先判断它属于哪一行，再套句式骨架。复盘时也按这张表找机会：先找对方话里"第一个不寻常的点"（见第 5 节），对上一行，再用 2–3 种不同招式各出一版。

| 对方在…… | 首选招式 | 句式骨架 | 例 |
|---|---|---|---|
| 抱怨一件小事 | 夸张附和 | "同意。我已经……"＋一个不相称的行动 | 「这家奶茶的珍珠越来越少了。」→「同意。我准备起诉，证据都数好了：七颗。」 |
| 调侃你 | 认同并放大 | "对。"＋一个更糟、更具体的证据 | 「你这车也太脏了。」→「对。它上次洗澡，车主还不是我。」 |
| 宣布计划、下决心 | 是的，而且 | 接受设定，在里面加一个细节 | 「我决定从今天开始存钱。」→「好。我帮你把购物车截个图，留作遗照。」 |
| 说出反常的数字、晒东西 | 如果这是真的 | 重复数字＋推出来的后果 | 「驾照终于考过了，第五次。」→「第五次？考官现在算你亲戚了吧。」 |
| 问日常问题（忙吗、周末干嘛） | 具体化 | 真实答案＋一个离谱的具体细节 | 「最近忙吗？」→「忙。昨天跟 Canvas 吵到凌晨两点，它赢了。」 |
| 说客套话（随便、改天、别太累） | 字面理解 | "好，那我……"（当真去办） | 妈妈：「别太累了，身体最重要。」→「好，那我这学期不读了。」 |
| 问一句能两解的话 | 故意曲解 | 挑对自己最不利的那层意思 | 「周末有空吗？」→「有。搬家还是借钱？」 |
| 做了件无害的好事 | 假装指控 | "举报了，这属于……"＋一个重罪 | 「我给群里每人点了份炸鸡！」→「行贿。收了。」 |
| 宣布小成就或小过失 | 文体错位 | 新闻联播体、公文通报体…… | 妈妈：「你爸今天第一次自己发了红包！」→「热烈祝贺我家数字化转型取得阶段性成果。」 |
| 夸你 | 身份错位 | 先抬一下，最后一个词摔下来 | 「你居然会修自行车！」→「会。YouTube 上学的，还没看到装回去那集。」 |
| 问你近况，而你刚倒霉 | 轻描淡写 | 平静陈述＋最平淡的总结 | 「实习面试怎么样？」→「挺顺利的。十分钟就结束了。」 |
| 说出自己的习惯或特点 | 情景构建 | "我们要是一起……" | 「我开车特别谨慎，黄灯一定停。」→「那我们要是拍警匪片，追车那场得拍三天。」 |
| 冷场，大家都不说话 | 说出显而易见的真话 | 说出大家心里那句 | （打烊后，大家擦着擦过的桌子，等店长说下班）→「我们现在都在假装还有活干。」 |
| 一件事第二次出现 | 回扣 | 只说关键的那个词 | （阿哲上个月说"我从不用导航"，然后在停车场找了一小时车）阿哲：「我到楼下了。」→「哪个停车场？」 |
| 讲自己的糗事 | 捧哏 | 追问一个细节，再补一句短话 | 「我上网课忘了静音，全班听到我妈喊我吃饭。」→「全班？？喊的小名还是大名？」 |
| 真的难过、在求助 | 不开玩笑 | 先接情绪，再问需要什么 | 「我实习被裁了。」→「我在。要不要打个电话？」 |

- 先练熟四招：是的，而且；认同并放大；如果这是真的；文体错位。熟到不用想，再加别的。
- 这和即兴课说的"别准备"不矛盾：要准备的是模式，不是台词。背好的台词会让你不再听对方说话。

## 4. 招式卡片

### 是的，而且（yes, and）

一句话：先接受对方抛出的设定，哪怕很夸张，在里面加一个新细节，再把球还回去。接受的是"一起玩"的框架，不是对方的观点。

公式：认出设定（"我要报警""我宣布""我要和 X 断绝关系"）→ 在设定里回答，不纠正事实 → 只加一个细节、后果或人物。

例：
- 朋友：「我决定了，从今天起和外卖断绝关系。」
  - ✗「你上周也这么说。」（挡回去，天聊死了）
  - ✓「好。分手要当面说，我帮你约它明晚七点。」

练：翻聊天记录，找 5 句朋友的抱怨或宣言，每句写一个"是的，但是"版和一个"是的，而且"版（只许加一个细节），看哪一版让话题变大了。

坑：一次加太多，把梗讲完了，对方没得接。

### 如果这是真的（if this is true, what else is true）

一句话：抓住对方话里反常的那一点，当它是真的，推出一个"逻辑上通、现实里荒唐"的后果。

公式：反常点 → 往时间、钱、身份、旁人、未来里挑一个方向推一步 → 留下最荒唐、还讲得通、离对方生活最近的那个。

例：
- 朋友：「我妈给我寄了二十包螺蛳粉。」→「那你室友该开始看房了。」（推法：二十包 → 味道 → 谁先受不了 → 室友）
- 朋友：「Duolingo 打卡四百天了，我还是不会点菜。」→「四百天？你这是在供那只鸟读书。」

练：选一个反常点，5 分钟内按时间、钱、身份、旁人、未来各推一步，每步写一句，最后圈出最好的一句。

坑：推得太远，逻辑断了，对方跟不上。

### 认同并放大（agree and amplify）

一句话：被调侃时不辩解、不反击，先认，再补一个更糟、更具体的证据。对方等着你辩解，你却自己补了一刀，较劲就变成了一起玩。

公式："对。"＋一个比对方说的更离谱的具体证据 → 停，不解释。

例：
- 朋友：「你这发型是自己剪的吧？」→「对。剪完还给自己付了 20% 小费。」
- 朋友：「你回消息也太慢了。」→「对。这条是我昨天开始打的。」

练：让朋友（或 Claude）连说 5 句温和的吐槽，每句都用"对"开头回，加一个更夸张的证据，10 秒内回完。

坑：放大得不具体（"对，我超烂"），或者放大完又补一句"开玩笑的，其实我……"。另外，对方是真的在伤人时别用，那等于默许别人欺负你。

### 夸张附和 / 小事说大（exaggerated agreement / mock gravity）

一句话：夸张升级（exaggeration）在聊天里的两种用法：对方的小观点，你用不相称的郑重去支持；对方的小倒霉，你用大事的框架去接。

公式：夸张附和＝"同意"＋一个极端而具体的行动；小事说大＝小事＋大事的框架（报警、悼词、遗嘱、新闻发布会）。

例：
- 朋友：「说真的，香菜就是难吃。」→「同意。我葬礼上要是有人放香菜，我会坐起来。」
- 朋友：「抱歉抱歉，迟到了五分钟！」→「没事，我刚报了失踪，现在去撤案。」

练：收集 5 个朋友常说的小观点（早八、冰水太冰、美式甜品太甜……），每个写一句"同意到离谱"。

坑：对方在认真抱怨一件要紧的事（被歧视、被欺负）时用，显得轻浮。

### 故意曲解（deliberate misinterpretation）

一句话：故意挑对方话里"错误但说得通"的那层意思来回。

公式：找一句能两解的话（寒暄、关心、随口一问）→ 挑对你最不利或最荒唐的理解 → 平静地回。最好用的变体：把关心听成审问，否认一件没人问的事。

例：
- 室友：「早，吃了吗？」→「没有。冰箱里那盒饺子不是我吃的。」
- 妈妈：「最近怎么不发朋友圈了？」→「没有，我没屏蔽你。」

练：列 10 句最常听到的问句（在干嘛、忙吗、有空吗、吃了吗），每句写一个"错误但说得通"的理解，再写一句回复。

坑：曲解太牵强，对方要想三秒才懂；或者滑成谐音双关（wordplay）。

### 字面理解（literalism）

一句话：把客套话、套话、反问句按字面当真，认真去办，给出一个荒诞的字面回答。

公式：认出套话（随便、改天、有空、随时找我）→ 假装没听出是客套 → 给一个认真、具体、能执行的回应。

例：
- 朋友：「你随便点，今天我请。」→「好。服务员，从第一页开始。」
- 同学：「你看到我的 AirPods 了吗？」→「看到了。上周二，在你耳朵里。」

练：列 10 句客套话（"改天聚""有空回来看看""随时找我""我先撤了"），每句写一个当真的回复。

坑：对方真着急时还字面回答，比如赶飞机前找不到护照。

### 假装指控（false accusation）

一句话：给对方一个无害、甚至值得夸的行为，安一个严重的罪名。表面是批评，其实是夸。

公式：无害行为 → 挑一个正式、严重的罪名（内幕交易、行贿、扰乱市场秩序、蓄意伤害）→ 简短"宣判"。

例：
- 同学：「我期末论文已经交了。」→「举报了。扰乱市场秩序。」
- 她（约会）：「我点的这个比你的好吃。」→「你来过这家吧？这是内幕交易。」

练：给 5 个无害的行为各编一个罪名：深夜晒美食、推荐好剧、抢到演唱会票、起得比你早、把你送的绿萝养活了。

坑：指控的是对方真正在意的事（成绩、钱），或者语气太认真。文字里罪名要明显荒唐，对不熟的人加个 [狗头]。

### 情景构建（scenario building）

一句话：从对方一个特点出发，搭一个"我们要是一起……"的虚构场景，给两人各分一个角色。

公式："我们要是一起 X（旅游、合租、开店、上综艺）"→ 对方的角色合理、甚至很帅 → 你的角色更惨、更荒唐。

例：
- 她（约会 app）：「我出去玩喜欢把每个小时都排好。」→「那我们要是一起旅游，你做 Excel，我当里面那栏'突发情况'。」
- 朋友：「我砍价从来没输过。」→「以后买二手车带上你。你砍价，我负责在旁边看起来很穷。」

练：选一个朋友的特点，用"我们要是一起合租 / 旅游 / 开店 / 上真人秀"各造一句，一共 4 句。

坑：太早暗示亲密，第一句就"我们结婚以后"，会给人压力。

### 文体错位（register clash）

一句话：用一种完全不搭的正式文体，回一件具体的小事。这是中文母语者的主场：这些文体大家太熟了，几乎不用解释。

公式：选一个大家都熟的文体 → 用它最招牌的两三个套话 → 内容必须是具体的小事。

例：
- 她（第一次约会后）：「今天我是不是话太多了哈哈」→「本次会谈气氛友好，双方就火锅蘸料问题坦诚交换了意见，同意下周继续磋商。」
- 妈妈：「怎么三天没回消息？」→「亲，您的消息正在排队，前面还有两个 deadline。」

练：把 5 条日常消息分别改成新闻联播体、公文通报体、客服体、论文摘要体，每条不超过 40 字。

坑：文体学得不像，就不好笑；写得太长也不好笑。

**中文文体库**

| 文体 | 招牌词 | 适合接 |
|---|---|---|
| 新闻联播体 | 近日、据悉、热烈祝贺、取得阶段性成果 | 小成就、家里的"大新闻" |
| 公文通报体 | 经查、系……所为、深刻反省、限期整改、特此通报 | 小过失、谁没洗碗、自己迟到 |
| 外交辞令 | 双方、坦诚交换了意见、表示严重关切、保留……的权利 | 小争执、谈判、约会之后 |
| 客服体 | 亲、已收到、正在加急处理、给您带来不便深表歉意 | 被催、回复慢、婉拒 |
| 论文摘要体 | 本研究、样本量、结果表明、有待进一步验证 | 失败的尝试、新体验、约会复盘 |
| 甄嬛体 | 本宫、想来、倒也不负、若是……那是极好的 | 撒娇、装腔（对方得看过） |
| 广播报站体 | 各位旅客、前方到站、请携带好随身物品 | 去睡觉、退出话题 |
| 发布会体 | 全新一代、重新定义、我们只做了一件事 | 晒新买的东西、新发型 |

再举一例，论文摘要体：朋友：「那个约会怎么样？」→「样本量为 1，暂无显著结论，建议重复实验。」

对方真生气时别用公文体和外交辞令，看起来像在推卸责任。

### 回扣（callback）与连续梗（running gag）

一句话：把早先出现过的一个细节，放进一个新的、意想不到的地方再说一次。反复用、不断压缩，就成了圈内梗。在约会里，回扣还顺便证明"我刚才在认真听"。

公式：前半段悄悄记下对方说的具体细节（数字、地名、糗事）→ 等一个相似的新情境 → 只说最关键的几个字，不解释出处。连续梗：第二次完整回扣，第三次以后压缩成一个词或一张表情包。

例：
- （约会开头她说：我邮箱里有三千封未读。一小时后，她手机震了一下）你：「第三千零一封？」
- （起源：小林说"我从来不坐错车"，当晚坐到了新泽西）
  - 一周后，小林：「放心，这次绝对不迟到。」→「嗯，你也从来不坐错车。」
  - 一个月后，小林：「这学期我绝对不挂科。」→「新泽西。」

练：回看今天的一段聊天，标出对方说过的 3 个具体细节，每个想一个它可能再出现的场合，写一句 10 字以内的回扣。

坑：解释出处（"你还记得你刚才说……"）。当着新朋友玩内部梗，先补一句来历，别把人晾在一边。

### 说出显而易见的真话（say the obvious）

一句话：观察吐槽（observational）的现场版。不追求原创，说出在场所有人都看见了、但没人说出口的那句话。真话本身就好笑，硬凹的笑点反而不好笑。

公式：冷场或尴尬时问自己"现在大家心里在想什么？"→ 用平静、略正式的语气说出来 → 不解释。

例：
- （小组群里，组长问"谁愿意做最后的 presentation？"，之后二十分钟没人说话）你：「这二十分钟，是我们组这学期最团结的时刻。」
- （约会结账时，两人同时伸手拿账单，又同时停住）你：「我们俩刚才都只伸了一半。」

练：想 5 个尴尬场景（电梯里遇到教授、网课没人开麦、长辈在家族群发养生文），每个 10 秒内写下"大家都在想、没人说的那句话"，不加修饰。

坑：说出的"真话"其实在揭某个人的短，比如点名谁没干活。

### 一本正经（deadpan）与轻描淡写（understatement）

一句话：用最平静的语气说离谱的话，或者把大事往小里说。不笑场，不加表情。

公式：轻描淡写＝平静地列出灾难＋一个最平淡的总结（"略有波动""不算理想"）；一本正经＝对一个荒唐的问题，给一句严肃、简短的"专业意见"。

例：
- 朋友：「今天怎么样？」→「航班取消，行李在丹佛，我在芝加哥。整体略有波动。」
- 朋友：「前任送的锅，我要不要扔？」→「锅是无辜的。」

练：写 3 件自己倒霉事的轻描淡写版；再给 3 个荒唐问题各写一句一本正经的回答。

坑：把别人的大事说小，显得冷漠，只对自己的倒霉事用。文字里对不熟的人一本正经，容易被当真，加个 [狗头] 或让内容明显荒唐。

### 具体化（specificity）

一句话：平淡的回答里，换上一个具体、意外、能拍成照片的细节。这个细节同时是留给对方的钩子。

公式：真实答案 → 后半句加一个具体到数字、方向、品牌或动作的细节 → 细节要符合"你自己的逻辑"。

例：
- 朋友：「周末干嘛了？」→「躺着。周六朝东，周日朝西，晒得均匀。」
- 爸爸：「最近吃得怎么样？」→「挺好，昨天吃了三种颜色的泡面。」

练：把"最近很忙""周末在家""还行吧"三句，各改成一个带离谱细节的版本，每句不超过 30 字。

坑：细节跟你本人无关，听起来像在背段子。

### 身份错位（status play）

一句话：先把自己抬高，再用最后一个词摔下来。

公式：摆出高姿态（熟客、专家、负责人）→ 用最后一个词戳破。中文社交对"装"很敏感，一定要摔得快、摔得明显。

例：
- 她：「这家店你选得真不错。」→「我是这儿的熟客。老板每次都热情地问：'第一次来吗？'」
- 朋友：「你怎么什么都知道？」→「我是家族群的首席辟谣官。任期内成功率：零。」

练：针对"被夸""出糗""点菜"三个场景，各写一句先抬后摔的回复。

坑：只抬不摔，就成了真吹牛。

### 现挂（riffing on the moment）

一句话：认识新朋友时不用"想"笑话，只要"听"：从对方的回答里抓一个最具体的词，放大一次，再把话头还回去。眼前的环境也是材料：菜单、装修、服务员的口头禅。

公式：问一个开放问题 → 听出回答里最具体或最反常的词 → 抓：重复它，语调上扬（顺便争取两秒）→ 放大：用"如果这是真的"或身份错位推一步 → 还：再问一句，让对方接着说。

例：
- 你：「你学什么的？」
- 对方：「精算。」
- 你：「精算？那你应该已经算出这段对话值不值得继续了。」
- 对方：「还在算。」
- 你：「那我说慢点，给你多点数据。」

练：和朋友练 3 轮，每轮问一个开放问题，圈出回答里的一个词，重复、放大、追问各做一次，每轮不超过 90 秒。

坑：放大完不还话头，开始自己表演。也别抓对方敏感的回答开刀（家境、成绩、身体）。

### 迟到回复（late reply）

一句话：好回复来晚了不白来：存进弹药库，下次同类情境直接用；或者干脆把"晚"本身做成笑点。法语管这叫"楼梯上的机智"（l'esprit de l'escalier），下了楼才想起该怎么回。

公式：事后写好的版本存起来，标上适用情境；还有机会，就正式补发："关于昨天那个问题，我认真想了一晚上，正式回复如下：……"

例：
- （当时）美国同学：「你们中国人都会功夫吗？」→「哈哈，不会。」（冷场）
- （第二天见到他）你：「关于你昨天那个问题，我想了一晚上。会，但不在我签证的允许范围内。」（英文同样成立：I do. It's just not covered by my visa.）

练：今晚就做一次：记下一个没接住的时刻（对方原话＋你当时的回答）→ 用 3 种招式各写一个事后版本 → 挑一条存进弹药库。

坑：复盘只写"我当时应该更好笑一点"，不写具体的句子。

## 5. 反应慢专项

"好回复总是事后才想到"，背后是三种不同的病，药也不一样：

| 原因 | 表现 | 解法 |
|---|---|---|
| 没招 | 不知道往哪个方向想 | 背速查表（第 3 节），先练熟四招 |
| 没看见 | 事后才发现"那句话明明能接" | 练找"第一个不寻常的点" |
| 不敢 | 想到了，但怕说错、想说得完美 | 降低目标（第 2 节），限时出手，允许失手 |

**"第一个不寻常的点"（first unusual thing）长什么样。** 听到这些信号，就是能玩的地方：

- 反常的数字（考了五次驾照、打卡四百天）
- 叫错的名字或称呼
- 绝对化的说法（"从来不""绝对""再也不"）：几乎都会被打脸，正好留着回扣
- 情绪和事情的大小不相称
- 场合不对：太正式或太随便
- 前后矛盾
- 之前出现过的细节又出现了（回扣的机会）

例：
- 朋友：「面试挺顺的，面试官人很好，就是全程叫我 Kevin。我不叫 Kevin。」
- 你：「恭喜 Kevin。」
- 另一个朋友：「Kevin 拿到 offer 记得请客。」

该抓的是 Kevin，不是面试：抓最怪的细节，别抓最大的话题。另外，对方说话时别在脑子里打草稿，一打草稿就会漏掉真正能玩的那个细节。

**合理地给自己争取时间：**

- 重复关键词，语调上扬："Kevin？？"重复本身就是一个节拍。
- 追问："然后呢？""他什么表情？"对方会继续给你材料。
- 先发一个表情包占位，再补文字。
- 文字聊天本来就有几十秒到一两分钟的回复空间，这是反应慢的人的主场，多在文字里练（群聊的窗口更短，见第 6 节）。
- 实在晚了，就用迟到回复，把"慢"变成笑点。

**练习阶梯（从易到难）：**

1. 当捧哏：群里有人讲糗事，只做三件事：追问一个细节、重复他最好笑的词、补一句 10 字以内的话。
2. 只找点，不出招：每天翻 10 条群消息或朋友圈，每条用一句话写出"第一个不寻常的点"，10 条里找出 7 个算过关。
3. 十秒三答：拿一句真实聊天里的话，10 秒内说出 3 个回复，每个用不同的招式，不许删改。每天 10 题，每周挑 5 条最好的存进弹药库。
4. 每晚复盘：一个没接住的时刻 → 3 个事后版本 → 存 1 条（见"迟到回复"）。
5. 暂停预测：看 crowd work 或综艺片段，在演员开口前按暂停，3 秒内说出你的回法，再跟他的比。
6. 和 Claude 陪练：回复时限从 30 秒开始，逐步缩到 5 秒。Claude 抛的每句话里，都要埋一个能抓的点（数字、称呼、绝对化的说法）。
7. 熟人群实战：每天至少一次"接住，再加一点"，然后再去不那么熟的场合。
8. 线下即兴课（Improv 101）：即兴训练能提高对不确定的容忍度；上完 10 周即兴课的中学生，社交焦虑也下降了（Felsman 等，2020、2022）。"反应慢"背后，常常是"怕说错"。

十秒三答示范，题目：朋友说「我房东又涨租了。」

- 如果这是真的：「再交两年，那个厕所该归你了。」
- 假装指控：「肯定是你上次把水龙头修好了，房子升值了。」
- 文体错位：「我方表示强烈不满，并保留搬走的权利。」

**心态。** 机智的人也常常没打中，只是出手的次数多；等那句完美的话，时机就过去了。真正有代价的是"不得体"，不是"不好笑"。

**说英语时。** 脑子要分一半去处理语言，反应自然更慢。先在中文里把招式练到不用想，再把最简单的几招带进英文：轻描淡写的 "Well, that went well."、认同并放大的 "Yeah, and…"、字面理解。

**怎么算进步。** 不只看讲响了几个笑话，更要看接住率（对方抛来的梗你接住了几个）、一起笑了几次、用过几种招、弹药库攒了几条。

## 6. 群聊与文字聊天

**拆分消息就是停顿（pause / timing）。** 一条消息只放一个笑点，25 字以内；要反转时拆成两三条，最后一条最短，只放笑点词。

- 朋友：「你这周学习怎么样？」
- 你：「很充实」
- 你：「天天泡在图书馆」
- 你：「楼下的星巴克」

别拆得太碎刷屏；别人在认真讨论时，别插进一个长段子。

**回应窗口。** 群聊话题凉得快，过了几分钟就别硬接，存起来以后回扣。群聊也不用每条都回，挑你真有东西可加的那条。

**接龙加码：夸张升级（heightening）。** 群聊里每个人的加码，都是在对上一个人说"是的，而且"。围绕同一个模式，每次只加一点，三轮左右就收。

- A：「楼里的烘干机又把我的毛衣烘缩了。」
- B：「缩成什么样了？」
- A：「现在像个护腕。」
- C：「再烘一次，就能当戒指求婚了。」

一上来就拉到最大，后面就没有台阶了；别人都停了，你也别再加。

**中文 emoji 不能照搬英文习惯。** 表情和语气词，相当于当面开玩笑时的表情和语调，告诉对方"我在闹着玩"。但它们在中文里有自己的意思：在微信上，🙂 和 😂 是中国青少年最常用来表示讽刺的两个 emoji（Cui 等，2024）。

| 符号 | 中文里常见的读法 | 怎么用 |
|---|---|---|
| 🙂 / 微信 [微笑] | 阴阳怪气、不爽 | 想表示友好时别用 |
| 😂 | 真笑，也可能是无奈、嘲讽 | 别跟在自己的笑话后面 |
| [狗头] | "我在开玩笑"，保命 | 冷面玩笑或调侃不熟的人之后，加一个 |
| 呵呵 | 冷笑、敷衍 | 别当"笑"用 |
| 单独一个"哈哈" | 礼貌、敷衍 | 想捧场，就重复他的金句或追问 |

同一句话，换个尾巴，读起来就不一样：

- 「选，我就喜欢被 deadline 追着跑的感觉🙂」读起来像真生气了。
- 「选，我就喜欢被 deadline 追着跑的感觉[狗头]」读起来像开玩笑。

对熟人，冷面可以不加标记；对不熟的人，加一个。每句都配表情，等于在解释笑话。别对长辈用年轻人的反讽 emoji。表情包本身也能当笑点，"认罪""装傻"类最好用，但要用对方圈子里认得的。

**语音。** 几秒钟的语气表演可以加分：一声长叹、一句方言、学一句对方的原话。用 60 秒的长语音讲段子，大概率没人点开。

**家族群。** 长辈转发养生文，别在群里当众辟谣、损人，长辈要面子。要玩就玩自己：

- 二姨：（转发）《隔夜菜致癌，赶紧告诉家人》
- 你：「收到。我冰箱那盒是上周的，不算隔夜。」

**当群里的捧哏。** 做法见第 2 节：追问、重复金句、补一句短话，再把话头还回去。别人的梗冷了，你接一句，这是最便宜的好人缘。

## 7. 约会与认识新朋友

**目标是一起笑，不是把对方逗笑。** 约会不是你的开放麦。接住对方的玩笑、顺着往下说，比另起一个自己的笑话值钱；对方讲好笑的事，你真的笑。

- 她：「我每次点外卖都备注'多放辣'，吃的时候又后悔。」
- 你：「所以你是每周花钱，让过去的自己惩罚现在的自己。」
- 她：「对！而且从来不长记性。」
- 你：「下次我帮你备注：'她说多放辣，别听她的。'」

**留钩子。** 回答太完整，对方就没法接。给一个具体细节，让对方有东西可抓。

- 她：「你周末一般干嘛？」
  - ✗「在家休息。」（答完了，没得接）
  - ✓「在重刷《甄嬛传》，第四遍了，已经能跟华妃对口型。」（她可以问"哪一句"，或者说自己也看过）

**约会 app 的资料（profile prompts）。** 别写"我很幽默"，写一个具体、好笑的事实。三条 prompt：一条好笑，一条真诚，一条留钩子。全是段子，会显得不认真。

- 「我们会合得来，如果……」→「你也曾把美国人说的 'We should hang out sometime' 当真，并且等了一个学期。」
- 「关于我的冷知识」→「我学会的第一句美式俚语是 no worries，到现在还用它回复所有我没听懂的话。」

**开场白（openers）。** 挑对方资料里最具体的一处 → 用提问、假装指控或小事说大接一下 → 只写一句，最好以问句结尾，让对方好接。

- （她的 prompt 写：我最不理性的恐惧——鹅）→「鹅的事我站你这边。它对你做过什么？」
- （他的资料写：每周去三次 Trader Joe's）→「一周三次？你在 Trader Joe's 有编制吧。」

别抄网上的万能开场白和土味情话；别一开场就带性暗示；别评价对方的长相。

**第一次见面：**

- 从现场取材，比背好的段子安全。调侃你们共同的环境（菜单、灯光、装修），不调侃对方。
  - （餐厅太暗，两人都打开手机手电筒看菜单）你：「我们现在看起来像在盗墓。」
- 用回扣：把对方前面说过的细节接回来。
- 情景构建可以用，但别太早暗示亲密。
- 自嘲（self-deprecation）要出于底气，不是讨好：笑过去的自己，不笑现在的核心能力；要具体；说完轻快地收，不等对方安慰；一次见面一两次就够。
  - 她：「你英语好好，在这边很久了吧？」
  - ✓「两年。头三个月，我接电话只会说一句：Sorry, can you text me?」
  - ✗「没有没有，我英语超烂的，我什么都不行哈哈。」
- 对方没笑，别更卖力。换成提问，把话头交给对方。

**明确不教：** 负面开场（negging，先贬低再示好）、推拉（忽冷忽热）、冷读（假装一眼看穿对方），以及任何故意让对方没有安全感的套路。这些是操纵，不是幽默。也不按性别教套路，统一以"一起笑"为目标。

## 8. 调侃的分寸

调侃（teasing / roast）＝玩笑式的挑衅＋一个"我在闹着玩"的标记，比如夸张、表情、语调（Keltner 等，2001）。标记没被读到，玩笑就成了攻击。

**开口前五查：**

1. 调侃选择，不调侃特征。买的东西、点的菜、追的剧、做的决定可以；长相、身材、口音、家庭、出身、学校排名、钱不行。
2. 挑对方自信、自己拿来开过玩笑的地方。对方先自嘲过的事最安全。
3. 往上打（punch up）：打比你强势的人、打规则、打机构，不打处境比你弱的人。
4. 人越少越安全：私聊 > 小群 > 大群 > 当众。中文里"面子"更要紧。
5. 带标记，看反应。对方笑了、回怼了，可以继续；沉默、回"……"、突然变客气、岔开话题，就停下来修复。

- ✓（朋友晒图：新买的加拿大鹅，两千刀）「好看。在洛杉矶，这件衣服的主要功能是防止你存钱。」（调侃的是一个选择，而且对方正得意）
- ✗ 拿对方的身高、口音、家里条件开玩笑。就算是熟人，在群里也别。

**红灯：这时别开玩笑。**

1. 对方在倾诉、求助，或者刚收到坏消息（被裁、分手、家人生病、签证出问题）
2. 话题涉及对方的身份、身体、家庭或经济困难
3. 权力差距大，又不了解对方的风格（教授、面试官、老板、刚认识的长辈）
4. 群里有不熟的人，而这个梗要靠圈内背景才懂
5. 你自己正在生气，这时的幽默会变成攻击
6. 文字聊天里，对方的回复越来越短、越来越冷

**绿灯：对方自己先开了玩笑。** 可以跟，但别比他更狠。小糗趁热接；大事要等，等时间过去，等当事人先开口（McGraw 等，2012：小糗离得近才好笑，悲剧要隔得远才好笑）。

- （当下）朋友：「签证被 check 了，可能赶不上开学。」→「太难了。要不要我帮你问问学校，能不能延期报到？」
- （两个月后，他自己先开玩笑）朋友：「我终于从 administrative processing 里出来了！」→「恭喜毕业。这是你在美国拿到的第一个学位。」

**调侃伤到人时：停、认、转。**

1. 停：不再加码，也不说"开个玩笑嘛"。
2. 认：具体说出是哪句话过了。
3. 转：真诚地肯定对方，再加一句轻轻的自嘲，把笑点转回自己身上。

- （你在群里说朋友做的蛋糕"像被车压过"，她回："……我做了三个小时"）
- 你：「抱歉，刚那句我嘴欠了。三个小时能做成这样，真的厉害。我上次烤的蛋糕，现在还在楼下当门挡。」

别说"你怎么这么开不起玩笑"；当众冒犯，就当众修复；道完歉，别马上又用同一个梗。

**锋利风格怎么用。** 用户喜欢犀利敢说的风格。观点可以狠，但对着在场的某一个具体的人，要降一档：锋利留给舞台（观众买票时就同意了被冒犯）和熟人小圈子；锋利要对准观念、处境和权力，不对准一个人改变不了的东西。给用户示范辣的版本时，同时给一个温和的版本，标清楚各自适合什么场合。

## 9. 冷场补救

笑话没人笑时，尴尬的不是笑话，是大家假装什么都没发生。你一句话点破，而且看起来一点都不受伤，紧张就松开了。

1. 有把握的笑话，先停一拍，给对方一秒钟反应。
2. 说一句点破当下或者自嘲的话。
3. 马上换话题。

- 群聊（你发了个笑话，十分钟没人回）：「行，这条我拿去家族群试试。」
- 当面（约会时你讲了个笑话，对方礼貌地笑了一下）：「这个笑话在我脑子里彩排的时候，掌声还挺热烈的。」
- 微信两分钟内可以撤回。撤回后补一句「大家什么都没看见」，也算救场。

救场一两句就够，别写成认罪书。不要解释笑话（"我的意思是……"），不要一直自责，不要甩锅（"你们不懂"）。接连冷场，就换话题，别硬撑。
