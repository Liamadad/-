好主意！我出三组，每组 4–5 条。每组里我都悄悄换了一个“变量”，先不剧透是什么，免得影响你判断。凭第一反应挑就行，笑出声的、嘴角动了一下的都算。

### A 组 · 上班

**A1** 老板给我画了三年的饼，我现在已经饼入膏肓了。

**A2** 上班三年，我最大的成长是能把“收到”打出好几种语气：“收到”是正常回复；“收到！”是领导在群里；“好的收到～”是我在假装开心；“收到。”——带句号的那个——说明我已经在刷招聘软件了。

**A3** 我们公司推行狼性文化，落实得特别彻底：开会不发言了，改成互相闻；领导一进门，全组翻身露肚皮；上周团建去了动物园——不是参观，是探亲。

**A4** 我的工作效率其实非常高：每天下午五点五十到六点这十分钟，能干完一整天的活。

**A5** 我休了七天年假。回来第一天，同事拍拍我：“最近挺忙吧？好几天没听你说话了。”——他以为我一直坐在那儿。

### B 组 · 家人

**B1** 我爸打电话永远只有一个话题：吃了吗。我说吃了，他问吃的啥；我说外卖，他说外卖不干净；我说那我自己做，他说你做的能吃吗。我还没想好怎么接，他已经说：“行，没事就挂了啊。”——我们家的“我想你了”，大概就长这样。

**B2** 我妈说她从来不催婚，只是“随口一提”。今年春节，她从除夕随口提到元宵，平均每小时一次，比整点报时还准。

**B3** 我爸总说他年轻时是全村最帅的。直到我看到他年轻时的照片，才明白这句话的重点在“全村”——那个村的适龄男青年一共三个，另外两个是他亲弟弟。

**B4** 我姥姥说过，看不到我结婚，她死不瞑目。所以我一直没结。她今年九十七，每天下楼跳广场舞。我妈骂我不孝，可我觉得，全家最孝顺的就是我。

### C 组 · 减肥

**C1** 我办了张健身年卡，一年去了三次，平均一次一千二——那是我这辈子洗过最贵的澡。

**C2** 我下了个减肥 App，每顿饭都老实记录。第一天它说：“今日摄入达标，继续保持！”第三天：“略有超标，明天加油哦～”第五天：“您今日摄入的热量，约等于一名成年男性三天所需。”第七天，它什么都没说，只弹出一个窗口：“是否需要联系您的紧急联系人？”

**C3** 我找了个健身搭子，结果俩人都是 i 人。现在我们每晚八点准时互发一句“练了吗”，再各自回一句“练了”，然后各自接着躺。主打一个互相提供情绪价值，体脂纹丝不动。

**C4** 健身房里最安静的器械是什么？——哑铃。

**C5** 朋友问我：“你最近是不是瘦了？”“嗯，在试一种新的减肥方法。”“什么方法？”“月底。”
