学 Burr 先拆一个误会：凶只是音量。他真正的招是**替坏的那边辩护**（devil's advocate）：大家都骂的，他偏要站过去，用一套还挺有道理的歪理越吵越凶，最后一刀捅回自己。

直接骂这个组员，听的人只会安慰你。替他辩护，靶子就挪开了：先挪到"leadership"这个词上，最后挪到你自己身上。

**轮到你。** 最后那句是我替你猜的。前面的歪理随便歪，最后这一刀必须是真事：Burr 凶完还招人喜欢，靠的就是它。你来填：

往自己身上找"嫌疑"：你也干过类似的事？你沾了他的光？还是有件事他敢、你不敢？写一句发我，我们一起磨。
