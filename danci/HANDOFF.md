# 交接说明：每日单词本项目

这份文件让本地会话（Claude Code 或 Codex）不看之前的云端对话也能接着做。项目文件都在 `danci/` 里。

## 项目是什么

给一个在香港读 IGCSE、准备升 IB 的高中生做的单词计划。妈妈负责检查，家人在微信上沟通。产出两个手机网页：

- `site/index.html`：每日单词本。弟弟每天用，妈妈检查时也用。
- `site/plan.html`：一页计划图，给妈妈看规则。

两个网页必须在香港和内地都能打开，所以不加载任何外部字体、脚本或 CDN，词库全部内置，只用手机系统字体。claude.ai 的预览链接在香港和内地很可能打不开，不能当正式链接给家人。

## 已经定下来的事（改动前先确认）

- 开始日期：2026-10-12（周一）。周一到周五学新词，周六周测，周日复习和补考。
- 计划延长到 2027 年底，共 64 周。最终考试在 2027 年 10 月，具体日期未定；定了以后要挪冲刺期。
- 每天新词：10 个默写 + 20 个认识。第三阶段和考后减半。冲刺期（2027-09-27 到 10-31）不学新词。
- 复习间隔：学完后第 1、2、4、7、15、30 个学习日，网页自动列出。
- 默写只要求写英文。妈妈点喇叭放发音，也可以读中文提示。
- 检查规则：
  - 每天：当天新词全部查，先打乱顺序。认识对 90%（20 个对 18 个），默写对 80%（10 个对 8 个）。没过就当晚重考错的那几个，不罚。
  - 周六：打乱后考前 30 个认识（对 26 个）、前 10 个默写（对 8 个）。
  - 每月最后一个周六：认识改为从学过的所有词里随机 50 个（对 38 个）。
  - 周测没过：周日补考一次；还没过，下周一到周五不玩游戏，周末照常。惩罚只看周六。
  - 复习的词弟弟自己打乱、遮住自测，妈妈不用查。
- 网页功能刻意保持最少，2026-10-10 按用户要求换成新设计：日期切换、几叠词、清单和卡片两种看法、打乱、发音、「开始检查」（随机抽题，自动计数，不保存）、「说明」，可以添加到主屏幕。清单上原来的「遮住」由卡片自测和「开始检查」取代，这是用户选的。没有账号，不保存数据，不同步。不要再加功能，除非用户要求；要拿掉或合并功能时，先问用户。
- 发音：先用有道词典音频 `https://dict.youdao.com/dictvoice?type=1&audio=<word>`（英式，香港和内地都能访问），失败时改用手机自带语音。云端测试环境连不上有道，**还没在真机上确认过有声音**。
- 设计：按 UI UX Pro Max 的检查清单过过一遍，按钮至少 44×44，有按下的反馈，浅色和深色都检查过。红色代表默写，蓝色代表认识，两个页面一致。没有采用它推荐的儿童字体和紫色主色。

## 词表

- 2026-10-10 妈妈要求加入经济、物理、数学的词（剑桥 CIE IGCSE，之后读 CIE A-Level）。已按考纲整理在 `subjects/`，排在最前面；每天仍是 10 默写 + 20 认识。见 README。

- 弟弟的水平不确定，所以认识词从 NGSL 常用词第 501 名开始，再接 ECDICT 里标为雅思或托福的词，按词频排序。
- 默写词：先学 570 个 AWL 学术词，再把认识过的、5 个字母以上的词按顺序升级为默写。
- AWL 词头是按标准词表整理的，没能跟官方原表逐字比对。中文释义从 ECDICT 自动截取，少数词的第一个意思比较偏，比如 formula 第一个是"客套语"。
- 详细来源、许可证和重新生成的命令见 `README.md`。

## 文件

| 文件 | 作用 |
|---|---|
| `app.html` | 单词本源码（片段，不含 `<html>` 外壳），数据位置是 `/*__DATA__*/null` |
| `plan.html` | 计划图源码（片段） |
| `words.json` | 词表数据：`S` 是默写，`R` 是认识，每项 `[单词, 音标, 中文]` |
| `build.py` / `load.py` / `awl.py` | 生成 `words.json`，源数据放在 `dl/`，或用环境变量 `DANCI_DL` 指定 |
| `assemble.py` | 把数据嵌进页面，输出 `site/`（完整网页）和 `out/`（claude.ai 预览用的片段） |
| `tests/` | `test.js` 测日程逻辑；`ftest.js`、`ftest2.js`、`shot3.js` 是 Playwright 页面测试 |
| `DEPLOY_PROMPT.md` | 发布到 GitHub Pages 的步骤，可以直接交给 Codex 用 computer use 执行 |

改日程：`app.html` 里的 `START` 和 `PLAN`，以及 `plan.html` 里写的日期，还有 `build.py` 里的 `SPELL_TOTAL` 和 `REC_TOTAL`。改完运行 `python3 assemble.py` 和 `node tests/test.js`。

## 还没做完的事

1. **上线**：已完成（2026-10-10）。网址是 https://liamadad.github.io/danci/ 和 https://liamadad.github.io/danci/plan.html，仓库 Liamadad/danci 的 main 分支。更新时运行 `python3 assemble.py`，把 `site/` 里的 8 个文件一起上传。
2. **真机测试发音**：在妈妈和弟弟的手机上各点几个喇叭。如果没声音，先换手机自带的浏览器试；还不行的话，排查有道音频在那台手机上能不能播放。
3. **两周后看难度**：如果前两周的认识词太简单，就把认识词的起点往后挪，改 `build.py` 里的 `ngsl_sorted[500:]`，重新生成。改之前要考虑已经学过的天数怎么衔接。
4. **考试日期确定后**：挪动冲刺期（`PLAN` 里的周次），并同步更新 `plan.html` 的阶段日期。
5. **计划图给妈妈**：可以发网址，也可以截长图发微信。
