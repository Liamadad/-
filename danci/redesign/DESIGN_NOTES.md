# 每日单词本 · 重新设计说明

从零设计，不改现有网站。现有 `site/index.html` 只作为最后对比的“现状”，不作为参考。

## 用户与主要任务

- 弟弟：香港 IGCSE 学生（之后读 IB 或 A-Level），每天用手机打开当天页面：先复习，再学默写词和认识词，点喇叭听发音，遮住后自测。
- 妈妈：每晚检查。先打乱，再遮住，从上往下考：默写词放发音让他写，认识词指着英文问意思，点一行看答案。
- 设备：手机竖屏，主要是 iPhone，也可能是安卓。香港和内地都要能打开，所以不加载外部字体、脚本或 CDN，只用系统字体。
- 主动作：看当天的词表 → 遮住 → 点一行看答案。

## 不能改的约束（来自 HANDOFF.md）

- 功能只有：日期切换、复习/默写/认识三个标签、遮住、打乱顺序、发音。不加账号、不存数据。
- 红色代表默写，蓝色代表认识，两个页面一致。
- 按钮至少 44×44，有按下反馈，浅色和深色都要检查。

## 品类与标杆

品类：背单词 App，同时也是家长的检查工具。

拆的标杆是“不背单词”：

1. 英文单词是画面主角，字号最大，音标小字压低。理由：认出单词就是核心任务。→ 保留
2. 默认深色。理由：多在睡前、通勤时用。→ 不保留，这里是晚饭后在桌上和妈妈一起用，浅色为主，深色跟随系统
3. 一屏一个词，底部三个大按钮（认识 / 模糊 / 不认识）。理由：一个人自测要快。→ 不保留，妈妈要一次看到整张表才能按顺序考
4. 释义先藏起来，点了才出现。→ 保留，就是我们的“遮住”
5. 自动播放发音。→ 改为手动点喇叭，因为妈妈要控制节奏
6. 顶部小数字显示进度。→ 保留，数字只当标签
7. 没有插画，内容本身就是画面。→ 保留

其他参考：墨墨背单词（记忆曲线、日历），Duolingo（厚按钮、强反馈；太幼稚，不适合高中生），以及学生手上的实物：默写本、单词卡、红笔批改、剑桥考卷。

  - 用户选 **03 单词卡**：灰蓝底上浮白卡、大圆角、厚按钮、留白多。要求**手机优先**。

  - 检查时**妈妈拿手机考，弟弟写本子**。页面要能单手操作：点喇叭、看答案、翻下一个都在拇指够得到的地方。

## 第 2 轮 · 版式方案（`round2-layout/style-explorer.html`）

三个方案都照“单词卡”卡片：底 #EEF1F5、白卡、圆角 16–20、厚按钮（底部 3–4px 实色阴影，按下陷下去）、红 #E5484D 默写、蓝 #3A6FF0 认识、复习用墨色 #1B2430。字体一律用系统字体栈：`system-ui, Roboto, Noto Sans SC, PingFang SC`，因为两台手机都是安卓。

核心对象是一个词（英文、音标、中文、科目、默写/认识）。主动词是“逐条处理”：妈妈一个个考。频率是每天一次，每次 15–30 分钟，两个人一起用。

### 用户反馈：提示字太多（2026-10-10）

用户说每张卡上都写“点卡片翻面”，看多了让人密恐。决定：

- 卡片上不写任何操作说明。遮住的部分用一块斜纹空白表示，卡背用浅色底，画面本身就说明“这里藏了东西”。
- 每次按“遮住”，底部闪一行小字（例如“点卡片看答案”），1.7 秒后自己消失，不挡操作，也不用关。
- 不做自动弹出的教程。完整用法和妈妈的检查规则放进右上角“?”里，想看才点开（做完整页面时加）。
- 第 2 轮三个小样已经按这个改了。

## 第 3 轮 · 完整页面（`site2/index.html`，源码 `app2.html`，用 `assemble2.py` 生成）

选定：03「一张一张考」+ 用户要求的清单视图。之后按用户要求加了「开始检查」（妈妈考或弟弟自己考都行）。

### 用户在制作中途的决定
- 清单给弟弟总览，卡片给弟弟自测（卡片本身就是一张一张遮住）。清单上原来的「遮住」由「开始检查」取代。用户选的是 A 方案，没有把清单遮住加回来。
- 周测、月考、补考：每按一次「开始检查」都重新随机抽题，弟弟提前自己考一遍也押不中题。只有中途刷新时保持同一套题。
- 妈妈每天只查默写和认识，复习归弟弟自己。

### 三处基本动效
1. 主操作：厚按钮按下陷 3px；点卡片做 3D 翻面（弹簧 0.5s）；「下一个」时旧卡往左飞出（最后 20% 才淡出），新卡从卡堆里弹上来，卡堆随进度变薄。证据：`shots/r3/motion-card/`、`shots/cmp/motion-next/`。
2. 状态切换：清单/卡片的分段滑块滑过去；换一叠时选中那叠抬起，内容按方向滑入。证据：`shots/r3/motion-switch/`。
3. 首次出场：三叠卡、切换栏、词卡依次升起，只在第一次打开时播放。证据：`shots/r3/motion-entry/`。

### 评审
- 第 1 轮盲评 7/10。改了：题面放大、每个词性一行、遮挡块改成胶带、换卡离场、「回到今天」改为墨色，删了 4 处多余文字。
- 任务走查：周测数量容易考错、听写中途会误打乱、切叠会露答案、最后一张之后按钮失效。都已修复。
- 第 2 轮盲评 7/10，没有提升，按规则停止打分循环。第 2 轮指出的问题已改：周测题、换卡叠字、释义断行、卡片上的弹出提示、「原顺序」灰字、「· 打基础」。
- 之后加的「开始检查」流程只做了自己走查和截图（`shots/ck/`、`shots/ck2/`），没有再送独立评审。

### 新旧对比（`compare-old-new.png`）

| 方面 | 旧网站 | 新设计 |
|---|---|---|
| 妈妈检查 | 先打乱，再遮住，一行行点喇叭，自己数对了几个 | 一个按钮走完：自动读音、带编号，对答案时点错的、自动计数，认识按会或不会，最后出结果，可以只重考错的 |
| 弟弟自测 | 整页遮住，点一行看 | 卡片一张一张翻 |
| 周测 | 页面显示本周 50/100 个，规则写“打乱后考前 10/30 个”，容易考错数量 | 每次随机抽 10/30 个，过关线写在按钮和结果上 |
| 拇指 | 遮住和打乱在页面上方 | 主要操作都在底部 |
| 刷新 | 打乱的顺序会丢 | 刷新后保留日期、顺序和考到第几个；重新打开链接一律回到今天 |
| 说明文字 | 每个标签上都有一段说明 | 页面上不写说明，放在右上角「说明」里 |
| 英文字体 | Georgia 衬线，在安卓上会变成别的字 | 系统黑体加粗（安卓上是 Roboto），更清楚 |
| 音标 | 词典的旧写法 'kælkjuleit | 学校词典写法 ˈkælkjʊleɪt |
| 科目 | 释义里写“（经济）” | 小标签 |

**保留的旧精华：** 日程逻辑一行不改；复习按学习日分组；默写词前的「写」字；过关线；回到今天；有道真人发音加手机发音兜底；不加载任何外部资源；开始前的「先看看第一天」；深色模式。

**去掉的旧糟粕：** 每个标签上的说明段落；放在上方的遮住和打乱按钮；“打乱后考前 N 个”；只靠颜色区分默写；刷新后顺序丢失。

**新设计的代价：** 代码量大约是旧版的两倍；「开始检查」的计数是新功能（不保存）；不同安卓品牌的系统字体会略有不同；还没在真机上试过。
